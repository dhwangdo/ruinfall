# C05-09 작업 기록: 용량이 찬 덱에 카드 넣기

상태: **완료**

## 범위

안전 구역에서 카드 25장이 든 덱 B에 인벤토리의 일반 카드 한 장을 실제 GUI 드래그한다. 덱 용량 초과를 알리고 이동을 거부하는지 확인한다.

## 검증 조건

- ID 1은 인벤토리, ID 2는 활성 덱 A, 덱 B는 고유 ID를 가진 일반 카드 25장으로 구성한다. 희귀 카드·티켓·제거 예정 카드는 사용하지 않는다.
- 현재 타일이 안전 구역임을 `MapRules.is_safe_area_tile()`로 확인한다. 안전 구역도 덱 용량 제한을 유지해야 한다.
- `Viewport.push_input`으로 인벤토리 카드에서 B 덱 행으로 실제 GUI 드래그한다.
- 확인: 인벤토리 ID 1 유지, B 카드 수 25와 ID 집합 유지, 모든 소유 카드 ID 보존, 활성 A와 mirror 및 편집 대상 A 유지, 용량 초과 안내 표시.
- 불일치가 나면 재현과 최소 원인을 분리한다. 20분 또는 두 번의 GUI 시도 안에 종료하고 commit/push하지 않는다.

## 결과

Godot 4.7.2 격리 프로젝트에서 `Viewport.push_input`으로 실행했다. 안전 구역에서 ID 1을 25장으로 찬 B 덱에 드래그했으며 GUI 드래그 시작, 용량 초과 안내, 인벤토리·A·B 상태 불변, 전체 소유 ID 보존, 활성 덱 mirror와 편집 대상 A 유지를 확인해 **9/9 통과**했다. 생산 코드 변경 없음.
