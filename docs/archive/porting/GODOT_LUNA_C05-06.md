# C05-06 작업 기록: 바닥에서 인벤토리로 카드 줍기

상태: **완료 · C05 전체는 미완료**

## 범위

안전 구역의 현재 타일에 놓인 일반 카드 한 장을 바닥 위젯에서 빈 인벤토리 슬롯으로 실제 GUI 드래그한다. 바닥에서 카드가 한 번 빠지고 인벤토리에 한 번 들어가는지, 카드 ID 총합과 활성 덱 A의 mirror 및 편집 대상 A가 유지되는지 확인한다.

## 검증 조건

- 일반 카드 ID 1은 현재 타일 바닥, ID 2는 활성 덱 A, ID 3은 보유 덱 B에 둔다. 인벤토리는 비우고 희귀 카드·티켓·제거 예정 카드는 사용하지 않는다.
- 현재 타일은 지도 `safe_area_entries`에 있는 안전 구역이어야 한다.
- `Viewport.push_input` GUI 마우스 이동·누름·누른 채 이동·뗌 순서로 드래그한다.
- 확인: 현재 타일 바닥에서 ID 1 제거, 인벤토리에 정확히 한 번 추가, 전체 소유 ID `{1,2,3}` 보존, 활성 A와 `run_state["deck"]` mirror 및 편집 대상 A 유지.
- 재현 범위를 넘어 규칙/저장 수정이 필요하면 Sol에게 인계한다. 20분 또는 두 번의 GUI 시도 안에 종료하고 commit/push는 하지 않는다.

## 결과 (2026-11-13)

- 안전 구역 현재 타일의 일반 카드 ID 1을 바닥 위젯에서 빈 인벤토리 슬롯으로 GUI 드래그했다. 바닥에서는 빠지고 인벤토리에 한 번 들어갔으며 덱 A ID 2와 덱 B ID 3은 그대로였다.
- 전체 소유 ID `{1,2,3}`, 활성 덱 A와 `run_state["deck"]` mirror, 편집 대상 A를 확인해 8/8 통과했다. 생산 코드 수정은 없다.
- 입력은 `Viewport.push_input`의 마우스 이동·누름·누른 채 이동·뗌이다. 물리 마우스 평가는 별도다. [GUI 보고](../outputs/godot-validation/2026-11-12-ui/c05-06-luna/c05-06-report.json).
