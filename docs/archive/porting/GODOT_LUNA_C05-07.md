# C05-07 작업 기록: 바닥 카드에서 덱으로 넣기

상태: **완료 · C05 전체는 미완료**

## 범위

안전 구역 현재 타일의 일반 카드 한 장을 바닥 위젯에서 보유 덱 B로 실제 GUI 드래그한다. 현재 타일 바닥에서 카드가 한 번 빠지고 덱 B에 한 번 들어가는지, ID 총합·활성 덱 A mirror·편집 대상 B가 맞는지 확인한다.

## 검증 조건

- ID 1은 현재 타일 바닥, ID 2는 활성 덱 A, ID 3은 덱 B에 둔다. 인벤토리와 바닥 카드 이외의 소유 카드는 고정한다. 희귀 카드·티켓은 사용하지 않는다.
- 현재 타일은 `safe_area_entries`의 안전 구역이어야 한다.
- `Viewport.push_input`으로 마우스 이동·누름·누른 채 이동·뗌 순서의 GUI 드래그를 보낸다.
- 확인: 바닥에서 ID 1 제거, 덱 B에 정확히 한 번 추가, 소유 ID `{1,2,3}` 보존, 활성 A와 mirror 유지, 편집 대상 B.
- 비안전 지역·희귀 카드·용량 제한으로 범위가 커지면 Sol에게 인계한다. 20분 또는 두 번의 GUI 시도 안에 종료하고 commit/push는 하지 않는다.

## 결과 (2026-11-13)

- 안전 구역 현재 타일의 일반 카드 ID 1을 바닥에서 덱 B로 GUI 드래그했다. 바닥에서는 빠지고 B에 한 번 들어갔으며 덱 A ID 2, 전체 소유 ID `{1,2,3}`, 활성 A와 mirror, 편집 대상 B를 확인해 최종 8/8 통과했다.
- 첫 probe는 덱 카드 ID의 정렬 순서를 기대값에 반영하지 못해 assertion 하나가 실패했다. 보고된 실제 배열은 정확히 `{1,3}`이었고 카드 이동 자체는 성공했다. 비교를 정렬한 뒤 GUI 경로를 재실행해 통과했다.
