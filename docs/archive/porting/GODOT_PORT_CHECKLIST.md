> 2026-11-14 사용자 요청으로 이 포팅 체크리스트의 추가 진행은 중단한다. 남은 미해결·승인 대기 항목은 기록으로 보관하며 자동으로 재개하지 않는다. 별도 마지막 요청인 승리 보상 창·자명한 버리기 자동 처리·선택 영역 강조·파일 드롭 범위 확대는 반영했고 관련 집중 검사를 마쳤다. 아래 상태는 과거 작업 기록이며 포팅 전체의 최종 사용자 승인을 뜻하지 않는다.

- 새 문제는 맨 위의 **아직 안 해결된 문제**에 적는다.
