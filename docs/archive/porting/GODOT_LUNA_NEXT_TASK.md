# Godot 작업 인계

현재 상태는 [문제 체크리스트](GODOT_PORT_CHECKLIST.md)의 **아직 안 해결된 문제**를 기준으로 한다. U01~U56 중 미해결은 U33 하나다.

## 최신 사용자 확인

- U12 생략된 애니메이션: 2026-11-14 사용자 해결 확인.
- U41 글자 흐림: 2026-11-14 사용자 해결 확인.
- 두 항목은 해결된 목록으로 옮겼다. 과거 기록의 미완료 표시나 배정을 이유로 다시 작업하지 않는다.
- 이번 요청은 체크리스트 정리다. U33 코드 수정은 이번에 진행하지 않았다.

## 앞으로 기록하는 방식

- 새 문제는 체크리스트 맨 위에 적고, 해결되면 같은 ID를 유지한 채 아래 해결 목록으로 옮긴다.
- 긴 기술 설명과 검사 기록은 [보관 문서](GODOT_PORT_CHECKLIST_HISTORY.md)에서 확인한다. 사용자에게 보여줄 목록은 짧게 유지한다.
- 메인 모델은 사용자가 선택한다. 메인 모델 전환을 서브에이전트 운영으로 대신하지 않는다.
- 브라우저와 다른 문제는 현재 브라우저 구현을 먼저 확인한다. 기존 작업본과 사용자 변경을 보존한다.
- 읽기·검색·git·검사는 RTK 우선. 코드 구조는 CodeGraph를 먼저 확인하고 미색인 자료는 현재 파일로 확인한다.
- 같은 오류 두 번 또는 15분 무진전이면 해당 작업의 현재 변경과 원인을 정리한다. 검사 코드만 계속 늘리지 않는다.
- commit/push/배포는 사용자가 요청한 경우에 한다.

## U33 참고 자료

- [브라우저와 Godot 전체 경로 조사](../outputs/godot-validation/2026-11-14-ui/u33-deck-drop/followup-current/audit.md)
- [기준본 재현 검사 실행 자료](../outputs/godot-validation/2026-11-14-ui/u33-baseline-main/run/report.json). 수정 완료 근거로 취급하지 않는다.
- 브라우저는 마지막 덱도 내려놓을 수 있고, 빈 소유 덱 목록을 저장·복원한다. 덱 없이 전투하면 패배한다.
- Godot의 마지막 덱 제한만 지우면 `decks[0]` 접근과 시작 덱 자동 생성 때문에 문제가 생긴다. 내려놓기·저장/복원·다시 줍기·전투를 함께 검토한다.
- U12와 U41의 과거 기술 메모는 보관 자료다. 새 사용자 제보가 없으면 다시 미해결 작업으로 올리지 않는다.
