# 프로젝트 인수인계 보고서

마지막 갱신: 2026-11-02

기준: 이 문서는 갱신 당시의 **현재 작업 트리**를 기준으로 작성했다. 커밋된 `main`보다 미커밋 코드가 앞서 있을 수 있다. 문서와 코드가 충돌하면 `app/`의 현재 코드를 기준으로 문서를 고치며, `tests/`는 동작을 검증하는 근거로 참고한다. 문서에 맞추기 위해 게임 동작을 바꾸지 않는다.

## 한 줄 요약

**Ruinfall**은 여러 파일에 쌓인 카드를 솔리테어처럼 재배열하며 싸우고, 넓은 그리드 지도에서 움직이는 적을 피해 탐험하는 싱글 플레이 웹게임 프로토타입이다.

현재 지도 틀은 7지역까지 생성되며, 실제 적 풀과 고정 보스 콘텐츠는 **1~3지역까지** 구현되어 있다. 카드 전투, 재련, 룰 카드, 덱 케이스와 에디션, 보상, 상점, 축복, 여러 지도 노드, 티켓, 보스 진행, 맵 진행 자동 저장과 전투 텔레메트리가 브라우저 안에서 동작한다.

## 현재 구현 범위

### 탐험

- 가로 `-160~160`, 지역당 세로 15칸인 7개 지역을 생성한다.
- 지역 사이에는 단단한 바위 5줄이 있다.
- 플레이어는 상하좌우와 대각선 8방향으로 움직인다.
- 지도 타일은 기존 136×136px 정사각형이며 장소·적 이름은 20px다. 적 이름을 감싼 표시만 내용에 따라 가로 124~208px로 늘어나고 높이는 내용에 맞춘다. 바로 옆 칸에 다른 적 표시가 있으면 폭을 128px로 제한해 겹침을 막는다. 들어가는 이름은 한 줄, 긴 이름만 두 줄로 줄바꿈한다. 휠·줌 버튼의 배율 간격은 0.04(4%p)다.
- 맵 화면의 최대 너비를 1280→1440px로 넓혔고, 지도 표시 높이는 `화면 높이 - 155px`로 늘렸다. 타일 크기와 전투 화면 크기는 유지한다.
- 지나온 길은 자동 이동할 수 있으며 적이 시야에 들어오면 자동 이동을 멈춘다.
- 지도에는 일반 상점·피의 상점, 추출·건강·심안·변환의 성소, 보물 상자, 축복 노드, 바위 군집, 지역 포탈, 바닥 카드·티켓이 생성된다.
- 조합의 성소는 제거했다. 피의 상점 가중치는 0.5이며 일반 재고 생성 후 가격을 올림(골드/15) 체력으로 변환한다. 구매 후 체력이 최소 1 남아야 하며 통화·체력 가격·매진 상태를 저장한다.
- 추출의 성소 내부 방 종류는 `extractionShrine`이다. 전용 모달·붕괴 상태와 동작 이름도 추출임을 명시하고 구버전 저장의 `collapsedShrineRooms`는 복원 시 새 이름으로 변환한다.
- 추출·변환 성소는 인벤토리와 같은 Pretendard 폰트와 분리된 어두운 패널을 사용한다. 추출의 목록·선택·결과는 모두 간소화 카드이며 정렬 버튼과 해당 상단 줄을 제거했다. 두 성소의 목록·선택·결과 카드에 마우스를 올리면 인벤토리와 같은 상세 카드 미리보기가 뜬다. 미리보기 상태는 목록과 분리하며 드래그 중에는 숨긴다. 보물 상자는 추가 굴림 횟수 배지를 표시하지 않는다.
- 카드·티켓·카드팩의 외형은 `CardVisual.tsx`와 `ConsumableVisual.tsx`가 담당한다. 모든 화면은 `variant="compact" | "full"`로 버전을 선택하고 입력·가격·선택 상태만 연결한다. 상점·보상·호버 미리보기는 큰 버전(136×191px), 인벤토리·성소·카드 목록은 간소화 버전(기본 82×82px)을 사용한다. 전투 파일·모바일 크기 조정은 같은 외형을 공유한다. 간소화 카드 이름은 등급과 관계없이 검은색이다. 티켓 설명은 일반 굵기(400)이며, 두 버전의 배경·그라데이션·테두리·글자색·티어 별은 공통 정의에서 가져온다. `ConsumableCardPreview.tsx`는 큰 버전을 띄우는 위치용 틀이다.
- 카드 기본 종이는 공통 `--card-paper: #e1dfd8`을 사용한다. `item-visuals.css`에 간소화 카드·티켓의 외형과 모바일 크기 변수를 모았고 기존 상점·인벤토리·성소별 외형 덮어쓰기를 제거했다. 카드 내용은 `CardVisual` 내부에서만 `CardFace`를 사용하며, 티켓 등급 표시는 `ConsumableVisual` 안에서만 조립한다. 카드 묶음의 뒤쪽 띠와 수량 표시도 공통 외형이 소유한다.
- 카드·티켓·축복·성소·적 설명에서 실제 등급을 뜻하는 단어는 `RarityText.tsx`로 굵게·해당 희귀도 색으로 표시한다. 추출 티켓의 특별, 소원·확장 티켓의 희귀, 폭사 방지의 희귀, 기본으로 돌아가기의 시작·일반 등이 대상이다. 일반 단어인 희귀도·턴 시작 시는 강조하지 않으며 카드 이름에는 적용하지 않는다.
- 발견 덱의 일반 칸은 빈칸 1/4·시작 1/8·일반 3/8·특별 1/4 비율로 생성한다. 희귀 슬롯 충전과 에디션 배분은 별도다.
- 빈 지도 칸의 0.5%에 카드나 티켓이 놓이며, 카드가 80%, 티켓이 20%다.
- 지역 포탈은 해당 지역의 안전 지역으로, 안전 지역 포탈은 다음 지역 시작점으로 이동시킨다.
- 1~3지역 안전 지역에는 고정 보스가 있으며, 보스가 살아 있는 동안 해당 안전 지역의 덱 편집이 잠긴다.
- 4~7지역의 지도와 안전 지역 틀은 있지만, 현재 일반 적 풀과 보스는 없다.

### 오버맵 적

- 탐험으로 새 지도 칸을 생성할 때 유효한 빈칸마다 4% 확률로 일반 적을 배치한다.
- 1~3지역에는 지역별 적 풀이 있으며, 3% 확률로 바로 다음 지역 적 풀이 조기 출현한다.
- 적은 `Zzz → ? → !` 인식 상태를 사용한다.
- 기본 최대 인식 거리는 거리장 2다. 어둠 티켓의 거리 감소가 있으면 1까지만 인식하며, 인식률 배율은 3칸의 0%를 증가시키지 않는다.
- 기본 시야는 반경 3의 7×7이다. 거리장 1·2·3에서 인식 상승은 각각 50%·12.5%·0%다. 깨어난 적은 거리장 4 이상에서 10% 확률로 잠들며, 경계 적은 거리장 5 이상에서 깨어남으로 돌아간다. 경계 유지 시 95% 확률로 접근하고 5% 정지하며, 상태가 바뀐 턴에는 이동하지 않는다.
- `!` 적은 지형과 다른 적을 고려한 8방향 거리장으로 추적한다.
- 여러 적은 목적지를 예약한 뒤 동시에 움직이며 일반 칸에서는 겹치거나 자리를 교환하지 않는다. 플레이어 칸에는 여러 적이 함께 들어올 수 있고, 겹친 조우는 체력을 이어서 연속 전투한다.
- 적의 현재 위치를 직접 본 칸에는 기억이 남고, 다시 관측하면 갱신된다.
- 플레이어나 적이 상대 칸에 들어가면 전투가 시작된다.
- 보스는 안전 지역 연결부에 고정되며 처음부터 `!` 상태다.

### 전투

- 카드 비행은 현재 확대·회전 자세를 보존하고 실제 손패 자세로 착지한다. 사용·버리기는 애니메이션 완료 후 상태를 바꾸며 보존 카드는 버리기 연출에서 제외한다. 적 공격은 이동 정점에서 피해를 표시하고 복귀 후 다음 타격을 시작한다. 초기화 시 진행 중인 비행과 이전 완료 콜백을 취소한다.
- 전투 중앙의 안내 메시지 띠는 표시하지 않는다. 버리기 선택에는 남은 장수를 적으며 중앙·적 대상 강조는 실제 사용 대상 판정을 공유한다. 적 턴의 강화·디버프·파일 버리기는 해당 대상 위 팝업으로 표시한다.
- 버리기 비용을 지불할 카드를 고를 때 사용 대기 중인 카드는 손패 화면에서 숨긴다. 비용 선택이 끝나면 기존 사용 처리로 효과를 해결한다.
- 카드에 약 1.5초 머무르면 재련·별 키워드에만 강화 애니메이션 창을 표시한다. 설명문 없이 파일 3개와 실제 CardFace·뒷면·전투 파일 간격·파란 배치 네온·주황 재련 네온을 공유한다. 별은 항상 타격으로 손패→첫 파일→다른 파일 이동과 별 두 번 소모를 시연한다. 재련은 실제 조건에 맞는 밑패 위에 놓고 강화 결과를 보여준다. 손패 136×191px, 파일 120.89×170px이며 한 주기는 기존 8.4초에서 5.6초로 단축했다. 오딘의 창은 다른 카드 재련과 창 비용 감소를 함께 표시한다. 시연용 강조에 별도 ::after를 쓰지 않아 실제 희귀도 띠를 덮지 않는다. 시연은 실제 전투 상태와 분리되고 드래그·스크롤·화면 전환 때 닫힌다.
- 선택한 덱을 섞어 기본 5장씩 파일에 배치한다.
- 강화 시연의 자원 표시는 전투와 같은 `BattleResources`를 파일·손패 사이 오른쪽에 놓는다. 카드 이동은 빠르게 출발해 느리게 멈추며 포인터의 흰 원은 제거했다. 실제 전투·시연의 재련 성공 시 카드 중심을 원 중심으로 한 주황 별 16개가 짧게 퍼지고 사라진다. 시작 원을 크게 잡고 확장 폭은 줄였으며 이동 감속과 투명도 변화를 분리한다. 반복·묶음 재련도 표시하고 초기화·종료·취소 시 연출을 정리한다.
- 기본 전투 시작 자원은 에너지 3, 별 2다.
- 턴 시작마다 비어 있지 않은 각 파일 맨 위에서 한 장씩 손으로 가져온다.
- 손패 카드 또는 파일의 카드 묶음을 다른 파일로 옮기는 솔리테어 행동은 별 1개를 쓴다.
- 공격, 물리 방어, 마법 방어, 힘, 강인함, 통합 저항·증폭, 추가 턴, 반사 등이 구현되어 있다. 저항·증폭은 부호에 따라 공격 피해를 ±30% 바꾸며 숫자의 절댓값은 지속시간이다. 음수는 보라색 디버프로 표시한다.
- `룰` 카드는 사용 후 전투 동안 활성 상태로 남는다.
- `소멸` 카드는 사용한 전투의 다음 리셔플에서 빠진다.
- 조건에 맞는 카드 위에 카드를 놓아 전투 동안 강화하는 `재련`이 구현되어 있다.
- 적이 유독성 점액·발효 점액·흙·돌·유물 토큰을 손패나 파일에 넣을 수 있다.

### 성장과 보상

- 기본 최대 체력은 50, 기본 인벤토리는 15칸, 기본 덱 케이스 보유 한도는 3개다.
- 시작 덱은 20장이고 시작 덱 케이스 용량은 25장이다. 타격·방어 각 6장과 몸 사리기·돌진을 포함한 일반 카드 8종 각 1장이다.
- 시작 덱은 전체 용량 25장 안에 빈 희귀 슬롯 1칸을 포함한다. 구버전 저장의 시작 덱도 희귀 슬롯을 최소 1칸 보장하며, 이미 확장한 슬롯은 유지한다.
- 새 탐험을 시작할 때 추가 타격·방어 카드를 지급하지 않는다.
- 일반 전투 골드는 지역에 따라 증가한다. 1지역은 10~15이며, 이후 지역마다 약 1.3배로 오른다. 보스 전투는 80~100 골드를 준다.
- 승리 보상창은 승리·골드·열쇠 수량과 보상·다음 버튼만 표시한다. 결과창의 문단·제목·버튼 스타일은 직계 자식으로 한정하여 공통 카드·티켓의 글꼴·색·자간을 덮지 않는다.
- 일반 전투는 카드 1장과 열쇠 1개를 주고 50% 확률로 티켓을 더한다. 일반 덱 드롭은 제거했다. 3% 미래 지역 적은 기존 덱 드롭과 열쇠 1개를 주며, 보스는 열쇠를 주지 않는다. 보스 학살자 축복의 추가 덱은 유지한다. 지도 복귀 시 골드·열쇠만 자동 획득하고 나머지는 전투 칸 바닥에 놓인다.
- 덱 보관소 미리보기는 인벤토리와 같은 `createDeckCardView`로 희귀 우선 정렬·같은 카드 xN 묶음·남은 희귀/일반 슬롯을 계산하고 `DeckSlotPlaceholder`와 공통 카드 외형을 사용한다. 덱 이름은 굵게, 희귀 슬롯 수치는 슬롯 그림으로 표시한다.
- 특수 지형은 총 1%, 그중 덱 보관소 `deckVault`는 0.5%다. 보관소 가중치를 나머지 가중치 합으로 계산해 다른 가중치 변경에도 0.5%를 유지한다. 맵에는 덱 이름을 표시하고 카드·에디션·용량·희귀 슬롯 미리보기 후 열쇠 3개로 한 번만 개방하면 같은 덱이 바닥에 나온다. 최초 생성된 덱과 개방 상태를 저장한다.
- 모든 포탈은 열쇠를 전부 없앤다. 열쇠가 있으면 “보유한 열쇠가 모두 사라집니다.” 경고와 “이번 런 동안 경고하지 않음” 체크를 표시한다. 취소하면 아무것도 소비하지 않고, 확정 때 생략 설정을 반영한다. 설정은 저장·복원되며 새 런에서 초기화한다.
- 일반 카드 보상에서 희귀 카드가 나오지 않을 때마다 희귀 확률이 2%p 증가하고, 나오면 5%로 돌아간다.
- 발견한 덱 케이스에는 전투 시작 자원, 파일 배치, 카드 공개, 골드 등에 영향을 주는 에디션이 붙을 수 있다.
- 축복 노드에서 세 후보 중 하나를 선택한다. 재추첨은 체력 5부터 시작하고 살아남은 재추첨마다 다음 비용이 2씩 증가한다. 미보유 축복이 부족하면 남은 축복을 중복 후보로 채운다.

### 도구와 디버그

- 우측 하단 버전 표시는 배포본에서 기존 커밋 시각을 유지한다. Vite 개발 서버에서는 app·public·build와 주요 설정 파일의 마지막 변경 시각을 한국 시간으로 표시하고 2초마다 새로 확인한다. 브라우저 새로고침만으로 시각을 바꾸지 않는다.
- 디버그 모드에서 모든 카드 덱, 카드 풀 통계, 70개 조우 레시피의 적 도감을 볼 수 있다. 바닥 생성 메뉴에서 모든 티켓을 한 장씩 생성할 수 있다.
- 디버그 모드의 덱 케이스 보유 한도는 10개다.
- 텔레메트리는 런·전투·턴·카드 사용·카드 획득·적별 받은 피해를 기록한다.
- 텔레메트리와 탐험 진행은 각각 브라우저 `localStorage`에 저장된다. 기록 내보내기 UI와 다운로드 함수는 제거했다.
- 탐험 진행은 맵 화면에서 자동 저장되어 새로고침 뒤 복원된다. 전투 중과 덱 편집 중의 상태는 저장하지 않으며, 패배하거나 새 탐험을 시작하면 진행 저장을 지운다.
- R키와 지도 상단 다시하기 버튼은 같은 1초 길게 누르기 초기화를 사용한다. 지도에서는 R키를 누르면 버튼의 게이지가 차며, 도중에 놓거나 창·탭을 벗어나면 취소된다. 전투 중 R키는 같은 초기화 로직과 별도 진행 안내를 사용한다.

주요 적 규칙:

- 상세 수치와 패턴은 `docs/GAME_DESIGN.md`의 현재 적 목록을 참고한다. 3랜덤1은 직전 행동을 제외하는 균등 무작위이며 같은 행동을 연속 사용하지 않는다.
- 1지역 혼합전은 50%이며 10조합 균등이다. 나머지 여섯 조우도 균등이고 쥐 3마리와 거병·인형술사를 포함하면 처음부터 다수전은 약 66.7%다. 순서 있는 혼합 20레시피(66~85)를 추가하고 기존 3·17·18·21·23번은 고정 혼합으로 변환한다. 2지역은 기존처럼 단독 7종 50%·혼합 50%, 혼합 15조합·30레시피(36~65)를 유지한다. 보스·3% 조기 출현·소환은 별도다.
- 기존 20번 금 간 수호상은 꼭두각시 거병(HP 상한 54)+인형술사(최대 HP 12 고정)로 대체했다. 인형술사는 공격하지 않으며, 처치하면 같은 조우의 거병만 다음 행동을 한 번 건너뛴다. 사망 효과는 한 번만 처리하고 폭발·지도 폭탄에도 적용한다. 갑옷 상태와 흡수 계산은 제거했다.
- 저주술사는 6번으로 복원했고 취약 3을 한 번 부여한 뒤 물리 공격 20을 반복한다. 마나 야수+도깨비불 8번은 삭제했다. 삭제 조우는 저장 복원 시 지도와 기억에서 제거한다.
- 1지역 24번 죄수는 null로 유지한다. 골렘은 약화 2→저항 2→공격 25+힘 5, 쥐 3마리는 각 공격 4 고정이다. 2지역의 기존 혼합 후보 ID 26·28·29·31·32·35는 고정 새 조합으로 변환하여 대표·기억·실제 전투를 일치시킨다. 호위병은 삭제했다.
- 유독성 점액은 턴 종료 시 남은 장당 물리 피해 12다. 발효 점액은 별개의 0코스트 에너지 1·토큰·보존 카드로 시작 시 2장 지급하며 힘 증가나 잔류 피해는 없다.
- 도깨비의 턴 종료 힘 +1, 광전사의 반피 힘 +7(한 번), 수색견의 손패 조건 임시 힘 +4은 패시브다. 피의 기수는 HP 상한 90이며 적 턴 종료 시 살아 있으면 양쪽 힘 +2를 부여한다. 전투 시작·추가 턴에는 이 힘을 주지 않고 반사·폭발로 죽으면 부여하지 않는다.
- 화약 운반병의 화약은 6에서 시작하고 해당 행동마다 2 증가한다. 사망하면 플레이어와 다른 적에게 그만큼 물리 피해를 주며 공격 배율을 적용하지 않는다. 방어·1UP·연쇄 폭발을 처리한다.
- 족쇄 간수는 기본 에너지 회복량만 1 줄이며 최대 에너지와 카드 효과는 유지한다. 최소 회복 1, 동일 패시브 중첩 없음. 처치하면 해제된다.
- 봉인은 매 플레이어 턴 새로 고른 유효 파일 하나에 적용한다. 자동·선택·무작위·천문학 연구 드로우를 모두 막고 솔리테어 이동과 재련은 허용한다. 봉인 파일을 표시하고 파수꾼 사망 시 해제한다.
- 압수관은 파일 배치를 끝낸 뒤 첫 드로우 전에 파일에서 무작위 희귀 카드 1장을 가져간다. 남은 카드를 다시 배치하거나 빈 파일을 없애지 않으며 노출된 맨 위 카드는 공개한다. 보유 중에는 리셔플도 막고 처치하면 즉시 손패로 반환한다. 희귀 카드가 없으면 압수하지 않는다.
- 적의 방어·패시브와 행동 불가는 버프/디버프 배지와 툴팁으로 표시한다. 인형술사의 사망 효과는 ‘인형 조종’ 배지로 설명한다. 저항·증폭의 음수는 취약·약화라는 이름과 양수 지속시간으로 표시하며 내부 상쇄 규칙은 유지한다.
- 1지역 혼합 후보 HP 상한은 들개 24·칼잡이 20·산적 26·두꺼비 26·하수구 쥐 28이다. 들개는 5→10→이후 5, 두꺼비는 4→4→폭발 12 후 자폭이며 예고한다. 칼잡이·산적·하수구 쥐는 3랜덤1, 칼잡이와 쥐의 힘 3·산적 임시 힘 5·쥐의 모든 행동 버리기 1을 유지한다.
- 발효 슬라임은 2지역 혼합 조우에 한 마리만 등장하며 HP 45·공격 10 / 5×2 / 증폭 2+저항 2다. 발효 점액 1장을 준다. 알집 바퀴는 첫 행동만 소환 고정이며 이후 3랜덤1이다.
- 소환된 새끼 바퀴는 HP 12·공격 4, 최대 2마리이며 소환 턴에는 행동하지 않는다. 본체가 죽어도 남은 새끼를 처치해야 승리한다.

## 카드와 덱의 현재 상태

- 카드 등급은 상태, 시작, 일반, 특별, 희귀, 전설이다.
- `ALL_CARD_BLUEPRINTS`에는 시작 2종·일반 8종·특별 38종·희귀 20종·전설 6종, 총 74종이 정의되어 있다. 특별 중 레거시 1종을 제외한 일반 특별 획득 풀은 37종이다. 별도 생성 카드 6종을 포함한 디버그 전체 덱은 80장이다.
- 응수·천문학 연구·강령학 연구·반전은 획득·생성·디버그 목록에서 임시 제외했다. 정의와 기존 저장 카드의 동작은 보존한다. 신규 특별 룰 사서의 특권은 2코스트이며 다음 플레이어 턴부터 기본 드로우 뒤 원하는 파일에서 1장을 추가로 뽑는다. 여러 장은 장수만큼 하나씩 선택하고 빈 파일·봉인은 제외한다. 파일 재배치 뒤에도 적용한다.
- 기회 창출·기회 포착은 드로우 대신 선택한 파일 맨 위 카드 버리기, 정리 타격은 이 버리기를 마친 뒤 드로우 1이다. 몸 사리기는 1코스트·버리기 1·방어 8, 기회 포착은 피해 9, 신규 일반 카드 돌진은 2코스트·버리기 1·피해 15다. 과감한 회피는 버리기 2·방어 13, 싸움 준비는 2코스트다. 저장 복원 시 기존 카드의 이름·수치를 갱신하고 진행 중인 덱 구성은 유지하며, 새 시작 구성은 새 탐험에 적용한다.
- 이름 변경: 비늘 갑옷→위압, 갈라치기→돌파구, 오시리스 선→별의 샘, 거울상→반전, 전술가→대전략가. 효과 키와 카드 ID는 유지하며 덱·인벤토리·바닥·상점의 구버전 카드 이름을 저장 복원 때 갱신한다.
- 철벽과 기존 마법 저항 가호는 삭제했다. 신규 가호는 통합 저항 2를 주는 별도 효과로 구현했다. 판금 갑옷은 1코스트·방어 5·저항 1[2]이며 재련 조건은 3코스트를 유지한다. 구버전 저장의 삭제 카드와 판금 갑옷은 모든 보관 위치에서 정리·갱신한다. 적의 횟수제 가호는 별개로 유지한다.
- 저항·증폭은 공격에만 적용하고 마도서·점액·반사·가시·체력 비용에는 적용하지 않는다. 힘 등 고정값을 더한 뒤 공격자의 증폭·대상의 저항·보스 학살자 등 배율을 곱하고 타격마다 마지막에 한 번 버림한 뒤 방어를 차감한다. 카드의 대상별 피해는 적 위로 드래그할 때 반영한다.
- 정상 턴마다 두 상태가 0을 향해 1씩 변하고 추가 턴에는 유지된다. 다음 턴 상태 부여는 자연 변동 뒤에 적용한다. 유리 대포는 자연 변동 외의 모든 저항 증가를 막으며, 취약 보험은 음수 저항 수치를 지우지 않고 피해 증가 효과만 무시한다. 덱 저항 에디션은 전투 시작 시 통합 저항 1을 준다.
- 저항·증폭 신규 카드 9종(특별: 기합·파쇄·무릎차기·가호·싸움 준비·위압, 희귀: 사계절·불굴·개박살)을 획득 풀과 화면·전투 계산에 추가했다. 사계절은 자신 외 손패 3장을 버려야 하며, 싸움 준비는 기본 회복 뒤 다음 플레이어 턴(추가 턴 포함)에 증폭·에너지를 각각 2씩 지급하고 중첩된다. 공격에 붙은 디버프는 타격 뒤 적용한다. 구버전 가호와는 다른 효과 키를 써서 저장 복원 시 보존한다.
- 저항·증폭 상태 툴팁은 현재 부호에 해당하는 실제 효과와 남은 턴 수를 표시한다. 취약 보험 보유 시 음수 저항의 피해 증가가 무효화된다는 설명을 표시한다.
- `무쇠 난동`은 레거시 카드 풀에 남아 디버그 전체 카드 목록에는 나타나지만 일반 획득 풀에는 연결되지 않는다.
- 늑대·거북이 부적은 전투 덱에 있는 장수마다 각각 힘·강인함 1을 준다. 구버전 저장의 값 2도 복원 시 현재 값 1로 갱신한다.
- 전설 카드 6종도 구현과 디버그 목록에는 존재하지만, 현재 일반 전투 보상·덱 생성·상점의 획득 풀에는 연결되지 않는다.
- 발견한 덱은 지역 번호로 용량·희귀 카드 수·에디션 예산을 정한다. 편차가 큰 조합은 지수 가중치로 드물게 뽑히며, `덱 크기` 축복은 생성이 끝난 뒤 용량 5장을 더한다.
- 새 발견 덱의 희귀 슬롯은 C=n+1+y, 실제 희귀 수는 C의 50~90% 비율을 확률적으로 반올림하여 정한다. 평균 70%이고 생성 덱은 최소 1장을 보장한다. 빈 슬롯을 유지해 저장하며 기존 덱은 소급 확대하지 않는다. 확장 티켓으로 슬롯을 추가할 수 있다.
- 덱에 원래 있던 희귀·전설 카드는 일반 이동으로 꺼낼 수 없다. 티어 2 추출 티켓+만 희귀도와 관계없이 추출하며, 제거 예정으로 만들어 편집을 확정하면 영구 제거된다. 추출 결과는 인벤토리, 인벤토리가 차면 바닥으로 간다.
- 일반 추출 티켓은 상태·시작·일반·특별 카드만 추출한다. 새로 넣은 희귀·전설 카드는 편집 확정 전 원래 위치로 되돌려 넣기를 취소할 수 있다.
- 덱 편집 이동 판정은 `app/game/deckEditorRules.ts`에서 카드 등급, 원래 덱, 희귀 슬롯 제한, 안전 지대, 티켓 종류를 검사한다.

- 카드 문장 맞춤은 같은 문구·폭·폰트의 결과를 최대 512개 재사용한다. 폰트 로딩 뒤에는 다시 측정한다.
- 2026-11-01 포인터 성능: 인벤토리 카드·티켓·에디션 미리보기 상태는 `DeckEditorPreviews.tsx`가 소유하고 `useDeckEditorPreviews.ts`로 이벤트만 연결한다. 같은 카드·호버 상태에서는 미리보기와 위치 측정을 반복하지 않는다. 전투 드래그 좌표는 ref에 보관하고 프레임당 한 번 미리보기 이동·대상 판정을 처리한다. React 상태는 드래그 시작·이동 시작·대상 변경·종료에만 갱신하며 손패 호버도 프레임당 한 번 판정한다. 종료·취소·화면 전환·언마운트 시 예약 프레임을 정리한다.
- 격리된 브라우저 비교에서 1,800회 이동 입력에 따른 상위 화면 렌더는 인벤토리 87→0회, 전투 드래그 90→3~4회였다. 미리보기 자체 갱신은 유지한다. 이 수치는 전체 게임 FPS나 모든 기기의 지연 개선율을 뜻하지 않는다.
- 텔레메트리는 이벤트를 메모리에 즉시 반영하고 최대 250ms 간격으로 저장한다. 런·전투 시작/종료와 페이지 숨김/종료 때는 즉시 저장한다. 초기화 시 예약 저장도 취소한다. 관련 회귀 검사는 `npm test`에 포함되어 있다.

- 검사: 타입 검사, 린트(오류·경고 0), `npm test`(규칙·연결 175개 + 서버 렌더링 1개), GitHub Pages 빌드가 통과했다. 브라우저에서 저장 복원, 전투 덱 선택·진입·카드 사용·적 턴·다음 드로우·승리 보상·지도 복귀, 성소 모달 진입을 확인했다. 이전 카드 표시·작은 화면 검사 결과도 유지한다.
- 4~7지역은 지도 틀만 있고 적 풀과 보스가 없다.
- 전설 카드는 정의되어 있지만 일반 플레이 획득 경로가 없다.
- 진행 저장은 맵 화면만 포함한다. 전투 상태와 덱 편집 상태는 새로고침 뒤 복원되지 않는다.
- 저장 스냅샷 직렬화와 구버전 복원값 정규화는 `tests/run-save-state.test.mjs`에서 확인한다.
- 광범위한 카드 효과와 지도 노드 UI는 적·오버맵 규칙만큼 독립 테스트가 촘촘하지 않다.
- `tests/deck-editor-rules.test.mjs`는 `npm test`의 규칙 테스트 묶음에 포함되어 있다.
- 무작위 보상과 덱 생성은 `Math.random()` 의존 구간이 많아 재현 테스트가 어렵다.
- 이 문서는 2026-11-02 현재 작업 트리의 코드와 문서를 대조해 갱신했다.
- 작업 트리에 사용자 미커밋 변경이 많을 수 있으므로 파일을 수정하기 전에 반드시 상태와 diff를 확인한다.

## 권장 다음 순서

1. 최신 스펙 분석과 수동 플레이 기록을 비교한다. 봉인 파수꾼·골렘·도깨비의 대응 비용과 화약 운반병의 누적 피해를 먼저 확인한다. 이전 승률 보고서를 다시 생성하려면 기록에 적힌 코드 버전을 사용한다.
2. 1~3지역을 실제로 연속 플레이해 적별 승률, 턴 수, 받은 피해와 카드 사용 기록을 수집한다.
3. 1~3지역 보스 처치, 안전 지역 잠금 해제, 다음 지역 이동을 직접 확인한다.
4. 흙·돌·유독성 점액·파일 버리기·가호·가시가 리셔플과 애니메이션에서 일관적인지 확인한다.
5. 전설 카드의 일반 획득 경로를 넣을지, 디버그·미래 콘텐츠로 유지할지 결정한다.
6. 새 지역·카드·적은 현재의 데이터·계산·연출 분리 구조를 유지해 추가한다.
7. 지도·전투의 남은 이벤트 연결은 크기보다 상태와 동작의 소유권이 함께 이동하는지 살펴보고 분리한다.
