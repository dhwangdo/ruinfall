마지막 갱신: 2026-11-08

## 문서와 코드의 기준

- 현재 동작의 기준은 `app/` 코드다.
- [GAME_DESIGN.md](GAME_DESIGN.md)는 플레이 규칙, [CODE_GUIDE.md](CODE_GUIDE.md)는 코드 구조, [MAP_REWORK.md](MAP_REWORK.md)는 지도 개편의 설계와 현재 차이를 설명한다.
- `docs/balance/`의 밸런스 보고서는 작성 시점의 역사 자료다. 현재 규칙과 다르면 코드와 `GAME_DESIGN.md`를 따른다.
- 질문이 아니라 구현 요청인 경우, 규칙·저장 변경의 영향에 맞춰 필요한 확인만 한다. 사용자가 플레이 테스트를 주로 맡으므로 작은 문서·UI 수정에 전체 테스트를 반복하지 않는다.

## 현재 게임 규칙

### 지도와 장소

- 세계는 7개 지역이며 각 지역은 212×47칸이다. 일반 지역 사이에는 바위 5줄이 있다.
- 일반 지역마다 덱 금고 30~35개와 수제 지형 금고 2개를 둔다. 제단 3개·땜장이 6개·변환기 3개·포탈 14~18개도 배치한다.
- 일반 상점·피의 상점·성소·보물 상자·무작위 회복/축복 노드는 일반 지도에 생성하지 않는다. 바닥 카드와 티켓도 자연 생성하지 않는다.
- 안전 지대에는 고정 축복·전체 회복·다음 지역 포탈이 있다. 1~3지역에는 보스가 있다. 진입 칸 오른쪽의 회복 지형은 최대 체력의 30%를 회복하고 사용 후 사라진다. 안전 지대에서는 보스 생존 여부와 관계없이 덱을 편집할 수 있지만 용량·희귀 슬롯 제한은 유지한다. 안전 지대 바닥에 티켓은 자동 배치하지 않는다.
- 덱 금고는 열쇠 3개로 한 번 열 수 있으며, 덱과 추출 티켓 1개가 바닥에 놓인다.
- O 자동 여행은 알려진 안전 경로로 미탐사 타일과 골드 더미를 탐사한다. 적의 인식 범위를 회피하고, 안전하게 갈 목적지가 남지 않으면 멈춘다. 새로 발견한 장소에서 자동으로 멈추지 않는다.

### 골드·보상·티켓

- 일반 전투는 열쇠 1개와 카드 1장을 준다. 미래 지역 적은 카드 대신 해당 지역 덱을 준다. 전투와 보스는 골드나 티켓을 주지 않는다.
- 보스는 스티커가 보장된 희귀 카드 2장을 준다. 보스 학살자 축복은 보스보다 한 지역 높은 덱을 추가한다.
- 일반 카드 보상의 기본 희귀 확률은 5%이고, 비희귀 카드가 나오면 다음 확률이 2%p 오른다. 희귀 카드가 나오면 5%로 돌아간다.
- 활성 티켓은 폭탄·추출·변환·복제·확장이다. 금고 개방은 추출 티켓 1개를 준다. 안전 지대 축복 중 폭탄마는 폭탄 8개, 변환가는 변환 4개, 거울상은 복제 2개를 준다. 심안·어둠·색칠·지도·추출+ 티켓은 현재 일반 획득 대상이 아니다. 카드 팩은 티켓과 별개다.
- 지역마다 96~111개의 골드 더미를 두며 합계는 1,000골드다. 더미 수는 덱 금고 수의 3배다. 타일에 들어서면 추가 턴 없이 줍고, 플레이어 위에 `+N`을 표시한다.
- 일반 카드 보상과 미래 지역 보상 덱의 각 카드에는 30% 확률로 **스티커**가 붙는다. 덱 금고 카드마다 확률은 2%다. 보스 카드에는 스티커가 반드시 붙는다. 덱 에디션은 카드 스티커와 별개인 덱 단위 설정이다.

### 카드와 전투

- 카드 스티커는 월석·태엽장치·책갈피·연·닻·야광공룡·파랑새·갈고리·낙하산·혜성 10종이다. 일반 카드는 한 개, DIY는 서로 다른 스티커를 최대 세 개까지 가진다. 시작 덱에는 스티커가 없다.
- 제단·땜장이·변환기는 카드를 선택해 사용한다. 기본 가격은 제단 $50, 변환기 $40, 땜장이는 스티커 종류별 가격이며, 같은 장소의 성공 횟수마다 1.5배로 오른다. 제단은 스티커가 정확히 한 개 있는 카드만 제물로 받는다. 제물·숙주 입력 슬롯은 어느 순서로든 드래그 배치할 수 있고 오른쪽에는 결과를 미리 보여준다. 변환기는 선택 카드의 같은 희귀도 후보와 스티커 교체 결과를 오른쪽에서 0.1초마다 순환해 예시로 보여준다. 이 미리보기는 확인 시 실제 결과를 고정하지 않는다.
- 1지역 보스 청소부는 HP 150이며 약화 2+취약 2 → 피해 15 → 피해 6×2 → 피해 10+힘 3 순서로 반복한다.
- 2지역 보스 간수는 HP 250이며 저항 2+증폭 2 → 피해 20 → 피해 20 → 힘 5 순서로 반복한다. 저항·증폭 효율은 패시브로 40%다.
- 4~7지역의 적·보스 콘텐츠는 아직 비어 있다. 전설 카드도 일반 획득 경로가 연결되어 있지 않다.

## 저장과 실행

- 웹 탐험 진행은 브라우저 `localStorage`에 저장·복원된다. 전투와 덱 편집 중 상태는 저장하지 않으며, 패배 또는 새 탐험 시작 시 진행 저장을 지운다.
- 데스크톱 실행기는 Electron 정적 앱이며 웹의 localhost 서버와 별도 저장 공간을 사용한다. 실행·빌드·갱신 절차는 [desktop/README.md](../desktop/README.md)를 따른다.
- 저장 범위를 변경할 때는 `saveGame.ts`, `runSaveState.ts`, `useRunPersistence.ts`와 관련 검사를 함께 확인한다.

## 주요 코드 위치

- `app/game/`: 카드·전투·지도·보상 등 순수 규칙과 계산
- `app/controllers/`: 지도 장소, 전투, 카드 이동, 티켓 동작 연결
- `app/hooks/`: 런 상태, 저장, 전투·지도 입력 상태
- `app/components/`: 화면과 입력 UI
- 지도 생성·배치: `mapRegionGenerator.ts`, `mapLocationPlacement.ts`, `mapPrefabDefinitions.ts`
- 골드 생성: `mapGold.ts`; 카드/전투 보상: `rewards.ts`; 스티커 확률과 효과: `stickers.ts`
- 스티커 서비스: `stickerServices.ts`, `useStickerServices.ts`, `StickerServiceModal.tsx`
- 티켓 획득: `deckVaultActions.ts`, `blessingActions.ts`; 티켓 사용: `ticketActions.ts`
- 1·2지역 적 데이터: `regionOneEnemies.ts`, `regionTwoEnemies.ts`
