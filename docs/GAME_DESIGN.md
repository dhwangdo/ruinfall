# 현재 게임 규칙

마지막 갱신: 2026-11-02

이 문서는 과거 기획안이 아니라 갱신 당시 **현재 작업 트리에 구현된 규칙**을 설명한다. 문서와 구현이 충돌하면 `app/`의 현재 코드를 기준으로 문서를 고치며, `tests/`는 동작을 검증하는 근거로 참고한다. 문서에 맞추기 위해 게임 동작을 바꾸지 않는다.

## 1. 게임의 큰 흐름

```mermaid
flowchart TD
  Start["탐험 시작"] --> Map["그리드 지도 탐험"]
  Map --> Enemy{"적과 충돌"}
  Enemy -->|예| Battle["솔리테어 카드 전투"]
  Battle -->|승리| Reward["골드·열쇠·카드/덱·티켓 보상"]
  Reward --> Map
  Enemy -->|아니오| Node{"지도 노드"}
  Node --> Shop["상점"]
  Node --> Shrine["성소·바닥 물품"]
  Node --> Portal["지역 안전 지대"]
  Shop --> Map
  Shrine --> Map
  Portal --> Safe["회복·축복·덱 편집·보스"]
  Safe --> Next["다음 지역"]
  Next --> Map
```

핵심은 두 층이다. 지도에서는 제한된 시야 안에서 움직이는 적과 지형을 읽고 경로를 선택한다. 전투에서는 여러 파일에 쌓인 카드를 꺼내 쓰거나 솔리테어 규칙으로 재배열하여 덱의 순서와 효과를 관리한다.

## 2. 지도와 탐험

### 지도 크기와 이동

- 가로 좌표는 `-160~160`이다.
- 총 7개 지역의 틀이 있으며, 모든 지역은 세로 15칸이다.
- 지역 사이에는 단단한 바위 5줄이 있다.
- 플레이어와 적은 상하좌우·대각선을 포함한 8방향으로 이동한다.
- 기본 시야는 플레이어 중심 반경 3, 즉 최대 7×7이다. 바위로 연결이 끊긴 칸은 같은 정사각형 안이어도 보이지 않는다.
- 이미 방문한 길을 클릭하면 자동 이동할 수 있다. 새 적이 시야에 들어오면 안전을 위해 자동 이동을 멈춘다.
- 지도 카메라는 드래그 및 확대·축소할 수 있다.
- 데스크톱 맵 화면의 최대 너비는 1440px이며 지도 표시 높이는 `화면 높이 - 155px`다. 타일은 136×136px 정사각형을 유지한다.

### 일반 지도 생성

| 요소 | 현재 규칙 |
|---|---|
| 특수 노드 | 일반 칸마다 1%. 덱 보관소 0.5%, 기존 장소 전체 0.5% |
| 바위 군집 | 일반부 약 3%, 가장자리 약 5% |
| 지역 포탈 | 지역 마지막 줄에서 5%, 없으면 하나 보장 |
| 바닥 물품 | 빈칸마다 0.5% |

특수 노드의 종류별 가중치는 다음과 같다. 이 값은 노드 종류를 고르는 상대 비율이다.

| 노드 | 가중치 |
|---|---:|
| 덱 보관소 (`deckVault`) | 나머지 가중치 합과 동일하게 자동 계산 |
| 추출의 성소 | 2 |
| 심안·변환의 성소 | 각각 1 |
| 상점·피의 상점·건강의 성소·보물 상자 | 각각 0.5 |
| 축복 | 0.01 |

덱 보관소는 다른 장소 가중치를 바꾸어도 전체 칸 기준 0.5%를 유지한다. 나머지 장소는 합계 0.5%를 위 상대 가중치로 나눈다. 고정 안전 지대 시설과 포탈은 이 무작위 특수 노드 추첨과 별도다.

바닥 물품은 카드 80%, 티켓 20%다. 카드인 경우 희귀 5%, 일반 30%, 특별 65% 비율로 풀을 고른다.

| 노드 | 효과 |
|---|---|
| 추출의 성소 | 덱 하나에서 희귀 카드를 제외하고 최대 2장을 바닥으로 꺼낸다. |
| 건강의 성소 | 최대 체력 +5. 현재 체력은 바뀌지 않는다. |
| 심안의 성소 | 20회 이동 동안 시야 거리 +2를 얻는다. |
| 변환의 성소 | 인벤토리 카드 2장을 변환한다. |
| 피의 상점 | 일반 상점과 같은 재고를 생성한 뒤 골드 가격을 15로 나누고 올림한 체력을 가격으로 사용한다. 구매 후 체력이 최소 1 남아야 한다. |
| 보물 상자 | 무작위 보상을 주고 큰 소리를 내 적을 깨울 수 있다. |
| 덱 보관소 | 맵에 덱 이름을 표시한다. 인벤토리와 같은 정렬·xN 묶음·빈 일반/희귀 슬롯으로 구성·에디션·용량을 미리 확인한 뒤 열쇠 3개로 개방하면 덱이 바닥에 떨어진다. 한 번만 개방할 수 있다. |

지역 포탈은 같은 지역의 안전 지대로 이동시킨다. 안전 지대 포탈은 다음 지역 시작점으로 이동시킨다. 어느 포탈이든 이용하면 보유 열쇠가 모두 사라진다. 열쇠가 남아 있으면 “보유한 열쇠가 모두 사라집니다.” 경고와 “이번 런 동안 경고하지 않음” 체크를 표시한다. 취소하면 이동·열쇠·경고 설정을 바꾸지 않는다. 경고 생략 설정은 같은 런의 저장·복원에 유지하고 새 탐험에서 초기화한다. 열쇠가 없으면 경고하지 않는다.

### 오버맵 적

- 탐험으로 새 지도 칸을 생성할 때 유효한 빈칸마다 4% 확률로 일반 적을 배치한다. 시야 주변과 여유 반경 안의 새 칸을 한 번씩 생성한다.
- 시작점 반경 2 안에는 일반 적을 생성하지 않는다.
- 1~3지역에만 현재 일반 적 풀이 있다. 4~7지역은 지도 틀만 있고 전투 조우는 없다.
- 적은 3% 확률로 다음 지역 풀에서 조기 출현한다. 다음 풀이 없으면 현재 풀을 쓴다.
- 적 위치는 직접 관측한 칸 단위로 기억된다. 그 칸을 다시 보면 기억을 현재 상태로 갱신한다.
- 플레이어가 적 칸에 들어가거나 적이 플레이어 칸에 들어오면 즉시 전투가 시작된다.

| 표시 | 상태 | 행동 |
|---|---|---|
| `Zzz` | 잠듦 | 이동하지 않는다. 거리장 1·2·3에서 각각 50%·12.5%·0% 확률로 깨어난다. |
| `?` | 깨어남 | 거리장 1·2·3에서 각각 50%·12.5%·0% 확률로 경계 상태가 된다. 거리장 4 이상이면 매 턴 10% 확률로 잠든다. 상태가 유지되면 50% 정지, 50% 무작위 이동한다. |
| `!` | 경계 | 95% 확률로 플레이어에게 접근하고 5% 정지한다. 거리장 5 이상이면 `?`로 돌아간다. |

기본 최대 인식 거리는 거리장 2이며, 어둠 티켓의 인식 거리 −1이 있으면 거리장 1까지만 인식한다.

상태 변화 자체가 그 적의 한 행동을 소비한다. 경계 적은 바위와 다른 적을 반영한 8방향 거리장을 사용한다. 여러 적은 먼저 목적지를 예약하고 동시에 움직이며 일반 칸에서는 겹치거나 서로 자리를 맞바꾸지 않는다. 플레이어가 있는 칸에는 여러 적이 함께 들어올 수 있다. 여러 조우와 충돌하면 체력을 이어서 순서대로 전투하고, 각 전투의 보상은 해당 전투 칸에 남긴다.

## 3. 안전 지대

- 각 지역에는 일반 지도와 떨어진 별도 안전 지대가 있다.
- 모든 안전 지대에는 축복, 전체 회복, 상점, 다음 지역 포탈이 있다.
- 1~3지역에는 추가로 고정 보스 1명, 회복의 성소 1개, 추출의 성소 2개가 있다.
- 보스는 안전 지대 연결부에 고정되고 처음부터 `!` 상태다.
- 보스가 살아 있는 동안 그 안전 지대에서는 덱 편집을 열 수 없다.
- 전체 회복과 축복 선택은 각 노드에서 한 번만 쓸 수 있다.
- 회복의 성소는 최대 체력의 30%(내림)를 회복하며 기본적으로 사용 뒤 무너진다. 금단의 지식이 있으면 이 회복량은 0이다.
- 추출의 성소는 덱 하나에서 최대 2장을 바닥으로 꺼낸다. 덱에는 최소 1장이 남아야 하며 기본적으로 사용 뒤 무너진다. 고고학자의 성소 보존 판정은 회복·추출 성소에도 적용된다.

## 4. 현재 조우 목록

아래 표는 코드에 정의된 생성 체력의 상한이다. 일반 적은 `floor(상한×0.9)`부터 상한까지의 정수 중에서 뽑으며, 쥐는 예외적으로 상한-1부터 상한까지 뽑는다. 인형술사는 최대 체력 12로 고정한다. 뽑힌 값이 초기 체력과 표시 최대 체력이 된다. 보스 체력은 표의 고정값이다. 신들의 비탄이나 지도 폭탄에 따른 전투 진입 체력 감소는 별도로 적용된다.

### 1지역

`3랜덤1`은 첫 행동을 셋 중 균등 선택하고, 이후 직전 행동을 제외한 둘 중 균등 선택한다. 아래 `/`는 선택지이며, `→`는 고정 순서다. 공격은 별도 표시가 없으면 물리, 힘·증폭·저항 보정 전 수치다. 힘과 자기 상태 획득은 공격 뒤 적용하며 플레이어 취약·약화는 다음 턴 자연 감소 후 적용한다.

|---|---:|---|---|
| 주황 슬라임 | 50 | 공격 10 / 약화 2 / 공격 7+힘 3 | 3랜덤1. 시작 시 유독성 점액 1장 |
| 하수구 쥐 | 28 | 공격 3×2 / 공격 6 / 공격 3+힘 3 | 혼합 후보. 3랜덤1. 매 행동 버리기 1, 파일 맨 위 중 높은 희귀도 우선 |

| 알집 바퀴 | 48 | 첫 행동 새끼 소환 → 이후 공격 10 / 새끼 소환 / 취약 2 | 첫 행동 뒤 3랜덤1. 새끼 HP 12·공격 4, 최대 2마리, 소환 턴에는 행동하지 않음 |
| 보스: 검은 슬라임 | 87 | 공격 10 → 방어 10+힘 2 반복 | 시작 시 유독성 점액 2장. 기존 보스 유지 |

1지역 일반전은 50%로 혼합 후보 5종 중 서로 다른 두 종류를 한 마리씩, 나머지 50%로 주황 슬라임·쥐 3마리·진흙 인형·꼭두각시 거병+인형술사·실을 짜는 거미·알집 바퀴 중 하나를 고른다. 혼합의 10개 조합은 각각 전체의 5%이며, 나머지 여섯 조우는 각각 전체의 1/12다. 쥐 3마리와 거병·인형술사 조우까지 포함하면 처음부터 다수전인 비율은 2/3(약 66.7%)다. 보스·3% 조기 출현·소환은 별도다.

대표와 행동 순서를 고정한 혼합 레시피 20개는 조우 66~85에 추가했다. 필드에는 `굶주린 들개 외 1마리`처럼 표시한다. 기존 3·17·18·21·23번은 대표 종류를 유지하는 고정 혼합 레시피로 변환하며 지도·관측 기억·실제 전투를 일치시킨다. 24번 죄수는 삭제 상태를 유지한다. 알집 바퀴의 새끼는 별도 보상이 없고 본체가 죽어도 남은 새끼를 처치해야 한다.

## 5. 플레이어와 덱

| 항목 | 기본값 |
|---|---:|
| 최대 체력 | 50 |
| 인벤토리 | 15칸 |
| 보유 덱 케이스 | 최대 3개 |
| 시작 덱 크기 | 20장 |
| 시작 덱 용량 | 25장 |
| 시작 덱 희귀 슬롯 | 빈 슬롯 1칸. 전체 25칸 중 희귀 1칸·일반 24칸 |
| 전투 시작 에너지 | 3 |

시작 덱은 타격 6장, 방어 6장, 몸 사리기·돌진·잽·전투 교본·자와 컴퍼스·기회 포착·기회 창출·별의 장막 각 1장이다. 시작·일반 카드의 모든 종류를 한 장씩 넣고 타격·방어를 각각 5장 추가한다. 시작 덱에는 에디션이 붙지 않는다.
새 탐험 시작 시 추가 타격·방어 카드는 지급하지 않는다. 시작 인벤토리에는 추출 티켓 1장이 있다.

새 탐험과 다음 지역 진입 시 신들의 비탄 충전은 3회다. 충전이 남아 있으면 다음 전투에서 적들의 진입 체력을 30% 줄이고 1회를 소모한다. 지역 포탈로 같은 지역의 안전 지대에 들어가면 남은 충전은 0이 된다.

발견한 덱은 지역 번호 n으로 기본 용량 `20+(n+x)×5`, 희귀 슬롯 수 `C=n+1+y`, 에디션 예산 `(n+z)×10`을 정한다. 채운 희귀 수는 C에 50~90% 균등 비율을 곱한 뒤 확률적으로 반올림한다. 결과가 k+p일 때 k장을 1-p, k+1장을 p 확률로 고른다. 생성 슬롯은 최소 2개이므로 희귀 0장은 없고, 평균 채움률은 70%다. 덱 크기 축복의 용량 +5는 마지막에 적용한다.

희귀 카드는 코스트와 이름을 밝은 금색(`#ffe08a`), 등급 띠를 단색 보라색(`#7138a6`)으로 표시한다. 간소화 스타일은 기존 레이아웃을 유지하며, 희귀 카드 본체 바탕은 일반 카드와 같은 `#f7f4eb`이다. 희귀 카드 테두리는 금색(`#d5a928`) 2px이고, 등급 띠 경계에도 같은 금색 선을 둔다. 텍스처는 희귀 카드 테두리 아래 층에 그린다.

일반 카드 바탕은 전투·목록에서 `#f7f4eb`, 덱 편집과 카드 미리보기에서는 밝기를 낮춘 회백색 `#e1dfd8`를 사용한다.

## 6. 전투와 솔리테어

### 전투 시작과 턴

1. 선택한 덱을 섞어 기본 5장씩 파일에 배치한다.
2. 각 파일의 맨 위 카드만 공개한다.
3. 턴 시작에 비어 있지 않은 각 파일 맨 위에서 한 장씩 손으로 가져온다.
4. 카드를 사용하거나 별을 써서 카드·파일 묶음을 재배열한다.
5. 턴 종료 시 남은 손패를 버린 뒤 적이 행동한다.
6. 다음 플레이어 턴에는 방어를 정리하고 에너지를 회복한 뒤 다시 파일마다 한 장씩 뽑는다.

카드 비행은 출발 시 확대·회전을 보존하고 실제 손패 위치·각도로 착지한다. 턴 종료 버리기는 보존 카드를 제외하며 마지막 카드의 비행 완료 후 적 턴으로 넘어간다. 적 공격의 피해 표시는 전진 정점에 맞추고, 다음 타격은 복귀 후 시작한다. 움직임 줄이기 설정에서는 비행을 생략하며 전투 초기화 시 남은 연출과 오래된 완료 처리를 취소한다.

모든 파일이 비면 버린 카드들을 다시 섞는다. 룰 카드, 이번 전투에서 소멸한 카드와 토큰은 다음 리셔플 대상에서 제외된다.

손패는 원호로 최대 9장까지 한 번에 표시한다. 표시 상한은 화면 폭에 맞춰 9·7·5·3·1장 중에서 정한다. 손패가 9장 이상이고 한 번에 2장 이상 표시할 수 있으면 휠로 한 장씩 이동해 볼 수 있다. 가장자리 밖으로 휠을 더 굴릴수록 저항이 강해지고, 휠 입력 중에도 가장자리로 되돌아오는 힘이 작용한다. 전투 중 스페이스를 누르면 그 순간 손패를 코스트 오름차순으로 정렬하고, 같은 코스트는 높은 희귀도부터 둔다. 사용 불가 카드는 비용 -999로 취급해 가장 앞에 둔다. 이후 카드를 뽑거나 버려도 자동으로 다시 정렬하지 않는다.

단일 대상 카드는 적에게 드래그하거나 카드를 선택한 뒤 적을 클릭해야 한다. 중앙 낙하나 더블클릭으로 첫 적을 자동 지정하지 않는다. 위압도 같은 규칙을 사용하며 전체·무작위·자신 효과는 중앙에서 사용할 수 있다.

사용 가능한 중앙·적 대상 강조는 카드 종류가 아닌 실제 대상 판정을 따른다. 전투 중앙의 안내 메시지 띠는 표시하지 않으며 버리기 선택에는 남은 장수를 적는다. 적의 강화·디버프·파일 버리기는 해당 행동 시점에 대상 위 팝업으로 표시한다.

카드에 약 1.5초 머무르면 재련·별 키워드에만 기본 설명 옆 강화 애니메이션 창이 나타난다. 강화 창은 설명문 없이 실제 CardFace·뒷면과 파일 3개를 사용하고 전투의 파일 간격·파란 배치 네온·주황 재련 네온을 그대로 공유한다. 별은 항상 타격을 손패→첫 파일→다른 파일로 이동하며 별을 각각 하나 소모한다. 손패는 136×191px, 파일은 120.89×170px이다. 재련은 실제 재련·배치 조건을 만족하는 밑패 위로 드래그하여 이름의 +와 강화 효과가 적용되는 모습을 보여준다. 오딘의 창은 다른 카드 재련과 창 비용 감소를 함께 표시한다. 한 주기는 5.6초로 이전보다 1.5배 빠르며 관련 예시가 여러 개면 주기마다 전환한다. 실제 전투 상태는 바꾸지 않는다. 창은 화면 공간에 맞춰 크기와 위치를 조절하고 드래그·스크롤·창 전환·Esc 입력 때 닫는다. 움직임 줄이기 설정에서는 정적인 결과를 표시한다.

### 자원과 카드 배치

- 카드 사용은 카드에 적힌 에너지를 쓴다.
- 손패 카드 또는 파일 위쪽의 연속된 카드 묶음을 다른 파일에 놓는 행동은 별 1개를 쓴다.
- 별은 턴마다 자동 회복되지 않는다.
- 파일 배치는 맨 위 규칙, 맨 아래 규칙, 주문 연쇄 규칙을 검사한다.
- 주문 연쇄는 비용이 이어지는 카드로 구성되며, 홍수 피라미드는 4-3-2-1 순서를 사용한다.
- 재련 카드를 조건에 맞는 대상 카드 위에 놓으면 일반 배치와 같은 별 비용을 쓴다. 여러 장을 함께 옮기면 모든 이동 카드가 이동 전 목적지 맨 위 카드와 독립적으로 판정되어 한 번에 여러 장을 재련할 수 있다.

### 피해·방어·상태

- 플레이어 공격에는 힘이 더해진다.
- 물리 방어와 마법 방어는 서로 다른 적 공격만 막는다.
- 강인함은 획득 방어에 더해진다.
- 기존 물리·마법 저항과 물리·마법 취약은 통합 저항·증폭으로 교체했다. 물리·마법 공격과 방어의 속성 구분은 유지한다.
- 저항이 양수이면 받는 공격 피해 ×0.7, 음수이면 ×1.3이다. 증폭이 양수이면 가하는 공격 피해 ×1.3, 음수이면 ×0.7이다. 수치의 절댓값은 지속 턴 수이며 배율의 강도는 중첩되지 않는다.
- 같은 상태의 양수·음수는 합산한다. 정상 턴마다 양수는 -1, 음수는 +1로 0을 향해 변하며 추가 턴에서는 유지한다. 적 행동에서 새로 얻는 상태나 다음 플레이어 턴의 상태 부여는 기존 값의 자연 변동 뒤에 적용해 즉시 사라지지 않게 한다.
- 힘·교본·거미의 다음 타격 보너스 등 고정값을 더한 뒤 증폭·저항·보스 학살자 등 모든 배율을 곱하고 마지막에 타격별로 한 번만 버림한 뒤 방어를 차감한다. 마도서·점액·반사·가시는 저항·증폭을 적용하지 않으며 체력 비용도 제외한다.
- 양쪽의 음수 저항·증폭은 보라색 디버프로 표시한다. 카드에는 내 증폭을 반영하고 적에게 드래그하면 대상 저항과 보스 배율도 반영한다. 적 의도는 공격자의 증폭과 플레이어 저항·취약 보험을 반영한다.
- 보통 방어는 다음 플레이어 턴에 사라진다. `견고한 태세`가 활성화되면 절반을 유지한다.

응수·천문학 연구·강령학 연구·반전은 임시로 생성·획득·디버그 목록에서 제외한다. 기존 저장에 이미 있는 카드의 정의와 동작은 보존한다.

- 사서의 특권: 2코스트 룰. 턴 시작 시 원하는 파일에서 카드를 1장 뽑는다. 사용 즉시 추가 드로우는 없으며 다음 턴부터 기본 드로우 뒤 파일을 선택한다. 여러 장이면 각각 한 장씩 선택하고 봉인된 파일은 고를 수 없다. 뽑을 카드가 없으면 선택을 생략한다.

- 빛무리: 0코스트. 광채 1장을 손패에 생성한다.
- 대형 프리즘: 3코스트. 광채 3장을 손패에 생성한다.
- 성운: 1코스트. 광채 1장을 손패에 생성하고 ★★를 얻는다.
- 5연격: 1코스트. 피해 2를 5번 준다.
- 백스텝: 0코스트. 방어 5를 얻는다.
- 은검: 1코스트. 피해 12를 주고 마법 방어 5를 얻는다.
- 별의 샘: 1코스트 룰. 매 턴 시작 시 ★를 얻는다.
- 재주넘기: 1코스트. 방어 9를 얻고 ★를 얻는다.
- 돌파구: 1코스트. 피해 9를 주고 ★를 얻으며 카드 1장을 뽑는다.
- 늑대 부적: 특별 등급, 사용 불가. 전투 덱에 있는 장수마다 힘 1을 얻는다. 인벤토리나 다른 덱에 있으면 발동하지 않는다.
- 거북이 부적: 특별 등급, 사용 불가. 전투 덱에 있는 장수마다 강인함 1을 얻는다. 인벤토리나 다른 덱에 있으면 발동하지 않는다.
- 퀵스텝: 1코스트. 카드를 2장 뽑는다.
- 정리 타격: 1코스트. 피해 9를 주고 선택한 파일 맨 위 카드 1장을 버린 뒤 카드 1장을 뽑는다. 버리기를 마치기 전에는 드로우를 할 수 없으며 버린 뒤 뽑을 카드가 없으면 선택을 종료한다.
- 과감한 회피: 1코스트·버리기 2. 방어 13을 얻는다.
- 싸움 준비: 2코스트. 다음 턴 시작 시 증폭과 에너지를 각각 2 얻는다.
- 판금 갑옷: 1코스트. 방어 5와 저항 1을 얻으며 재련 시 저항 2를 얻는다. 재련 조건은 3코스트다. 철벽·카드 가호는 삭제했고 구버전 저장에서도 제거한다.
- 광채: 0코스트 토큰 공격. 기본 피해 4이며, 이번 턴에 먼저 사용한 다른 광채마다 피해가 4 증가한다.

이 그룹에는 룰·소멸·재련, 드로우와 자원 변환, 광역 공격, 반사, 수동 지속 효과 등 전투 구조를 바꾸는 카드가 집중되어 있다. 개별 수치의 단일 기준은 `app/game/cards.ts`의 카드 정의이며, 비용·재련·배치 판정은 `app/game/cardEffects.ts`에 있다.

## 8. 덱 에디션

발견 덱의 에디션은 지역 생성식의 에디션 예산에서 고른다. 남은 예산 이하이고 충돌하지 않는 에디션만 후보가 되며, 후보별 선택 가중치는 `에디션 점수^1.2`다. 같은 에디션은 중복되지 않으며 `재활용`과 `재활용+`는 함께 생성되지 않는다.

## 9. 전투 보상과 발견 덱

- 일반 전투 골드는 지역 번호 `n`에 따라 `floor(10×1.3^(n-1))`~`floor(15×1.3^(n-1))`이다. 보스는 80~100 골드를 준다.
- 탐욕스러운 에디션과 탐욕 축복은 각각 골드를 2배로 만든다.
- 일반 전투는 덱을 드롭하지 않고 전투 한 번당 열쇠 1개를 추가로 준다. 다수전과 소환 적도 전투당 1개다. 기존 덱 드롭 확률 증가와 첫 3전 보장은 제거했다.
- 3%로 조기 출현한 미래 지역 적은 기존처럼 해당 적 지역의 덱을 보장하며 열쇠 1개도 준다. 보스는 열쇠를 주지 않는다.
- 덱 케이스가 나오면 독립 카드 보상은 나오지 않는다. 덱 케이스가 없으면 카드 1장을 받는다.
- 카드 희귀 확률은 5%에서 시작한다. 희귀가 아니면 2%p 오르고, 희귀가 나오면 5%로 초기화된다.
- 희귀가 아닌 카드 보상은 일반 약 31.6%, 특별 약 68.4% 비율이다.
- 일반 전투의 티켓 보상은 덱 케이스가 나오지 않았을 때 50% 확률로 1개 나온다. 덱 케이스가 나오면 이 일반 티켓 보상은 없다.
- 전투 종료 후 지도에 복귀할 때 골드와 열쇠는 자동 획득하고, 보상 카드·덱 케이스·티켓은 해당 전투 칸의 바닥에 놓인다. 상점 구매품과 카드 팩에서 나온 카드는 인벤토리에 넣고, 넘치는 물건을 해당 바닥에 놓는다.

덱 보관소의 덱은 지형이 속한 지역 번호로 생성하며 최초 생성된 이름·내용을 저장한다. 미리보기·개방·재방문·새로고침에서 다시 뽑지 않는다. 열쇠는 인벤토리 칸을 쓰지 않으며 상단에 별도로 표시한다. 미래 지역 적이 드롭하는 발견 덱은 적의 지역 번호 `n`으로 생성한다. 보스 전투는 일반 전투 확률과 별개로 희귀 카드 1장과 티켓 2개를 보장하며, 보스 학살자 축복이 있으면 보스보다 한 지역 높은 덱도 준다.

## 10. 티켓과 상점

| 티켓 | 효과 |
|---|---|
| 색칠 | 덱 카드 한 장의 뒷면을 무지개색으로 변경 |
| 심안 | 20회 이동 동안 시야 거리 +2 |
| 어둠 | 20턴 동안 적의 인식 거리를 1 줄임 |
| 폭탄 | 점화 뒤 3회 이동하면 3×3 범위에 피해 20. 적뿐 아니라 플레이어도 피해를 받으며 폭탄마는 면역. 범위의 상점은 파괴되고 바위는 세 번 맞으면 파괴 |
| 복제 | 카드 또는 티켓 하나를 복제. 전설 카드와 복제 티켓은 복제 불가 |
| 추출 | 덱에서 상태·시작·일반·특별 카드 1장을 추출 |
| 추출+ | 티어 2. 덱에서 희귀도를 가리지 않고 카드 1장을 추출하며, 희귀·전설 카드 추출은 이 티켓으로만 가능 |
| 확장 | 티어 3. 덱에 드래그해 희귀 슬롯 1개를 추가 |
| 변환 | 카드는 같은 희귀도의 다른 카드로 변환하고, 티켓은 티어와 관계없이 다른 티켓으로 균등 변환. 전설 카드는 변환 불가 |
| 지도 | 같은 지역의 아직 드러나지 않은 특수 지형 2곳 공개 |
| 카드 팩 | 카드 5장 획득. 현재 상점 전용 상품 |

상점 재고는 서로 다른 특별 카드 3장, 추출 티켓 1장, 추출 티켓+ 1장, 서로 다른 무작위 티켓 2장, 카드 팩 1개, 희귀 카드 1장이다. 두 고정 추출 티켓과 무작위 티켓 2장은 서로 겹치지 않는다. 무작위 티켓은 추출 티켓과 추출 티켓+를 뺀 나머지 티켓에서 균등하게 뽑는다.

피의 상점의 재고 구성과 골드 기준 가격 생성은 일반 상점과 같다. 가격 생성 후 체력 가격 = 올림(골드 가격 / 15)로 한 번 변환한다. 체력 비용은 피해가 아니며 구매 후 최소 체력 1을 남겨야 한다. 골드는 사용하지 않는다. 통화·가격·매진 여부를 함께 저장하여 재방문·복원 때 다시 변환하지 않는다.

가격은 지역 배율 `1.3^(지역 번호-1)`을 곱한 뒤 기준가의 80~120%에서 정한다. 특별 카드 기준가는 50골드, 카드 팩은 120골드, 희귀 카드는 160골드다. 티켓 기준가는 `30 + (티어-1)×50`골드다.

| 티켓 티어 | 티켓 |
|---:|---|
| 1 | 색칠, 폭탄, 추출, 지도, 심안, 어둠 |
| 2 | 추출+, 변환 |
| 3 | 복제, 확장 |

지도 티켓의 색은 갈색이다. 점화한 폭탄은 바닥에 내려놓고 덱 편집을 확정하면 설치된다. 인벤토리에 들고 있어도 이동 카운트가 진행된다.

보물 상자는 기본 3회 추첨한다. 매 추첨은 덱 20%·특별 카드 20%·희귀 카드 20%·티켓 30%·추가 추첨 2회 9%·추가 추첨 5회 1%다. 추가 추첨에서도 같은 추첨이 이어진다. 보상은 상자 칸의 바닥에 놓이며, 거리 5 이내의 보스 외 적은 잠듦→깨어남, 그 외 상태→경계로 변한다.

## 11. 축복

축복 노드는 아직 얻지 않은 축복에서 후보 3개를 뽑는다. 재추첨할 때는 이번 선택 화면에서 이미 보인 후보를 우선 제외한다. 후보가 부족해도 미보유 축복이 남아 있으면 그 축복을 중복해서 채우며, 미보유 축복이 하나도 없을 때만 `빈 축복`으로 채운다. 축복은 안전 지대 외의 낮은 확률 노드에서도 얻을 수 있다.

## 12. 덱 편집

- 덱 이름 칸을 한 번 클릭하면 편집 대상만 바뀌고, 더블클릭하면 사용할 덱이 바뀐다. 편집 창을 닫을 때 편집 대상을 자동으로 사용 덱으로 바꾸지 않는다.
- 편집을 열 때 모든 카드의 원래 덱 ID를 기록한다.
- 안전 지대에서는 희귀·전설 카드 외의 카드를 덱, 인벤토리, 실제 바닥 사이에서 자유롭게 옮길 수 있다. 단, 보스가 살아 있는 안전 지대에서는 편집 자체가 잠긴다.
- 안전 지대 밖에서는 원래 덱 카드가 그 덱에 묶인다. 바닥으로 빼면 즉시 실제 바닥에 놓이지 않고 제거 예정이 된다.
- 금단의 지식이 있으면 전투 밖의 모든 지역에서 안전 지대의 일반 덱 이동 규칙을 사용한다.
- 제거 예정 카드는 원래 덱으로만 되돌릴 수 있으며, 편집 확정 시 제거된다.
- 새 발견 덱의 희귀 슬롯 수는 생성식의 C이며 실제 희귀 카드 수와 독립적으로 저장한다. 빈 슬롯이 있는 덱도 생성된다. 확장·제거·추출로 빈 슬롯을 만들 수 있고 시작덱은 슬롯 0개다. 기존 저장 덱의 슬롯 수는 소급 확대하지 않는다. 희귀·전설을 넣을 때 슬롯과 전체 용량 제한을 함께 검사한다.
- 희귀·전설 카드는 인벤토리나 바닥에서 덱으로 넣을 수 있고, 바닥에서 바로 덱으로 옮길 수도 있다. 덱에서 다른 덱으로 직접 옮기는 것은 불가능하다. 새로 넣은 카드는 덱 편집을 확정하기 전까지 원래 인벤토리·바닥 위치로 되돌려 넣기를 취소할 수 있다.
- 덱에 원래 있던 희귀·전설 카드는 안전 지대 여부와 관계없이 일반 이동으로 인벤토리나 바닥에 돌려놓을 수 없다. `추출 티켓+`로 추출하거나 제거 예정으로 만들어 편집을 확정해 영구 제거할 수 있다. 추출 티켓+ 추출 결과는 인벤토리로 가며, 인벤토리가 가득 차면 바닥에 놓인다. 희귀 카드를 제거 예정으로 지정하면 해당 슬롯은 즉시 비워져 다른 희귀 카드를 넣을 수 있다. 슬롯이 모두 차면 되돌릴 수 없으므로, 빈 슬롯을 만든 뒤 되돌려야 한다.
- 일반 추출 티켓은 상태·시작·일반·특별 카드만 추출한다. 티켓을 쓸 수 있는 덱 카드는 편집 시작 당시 해당 덱에 있던 카드뿐이다. 일반·특별 카드 추출 결과도 인벤토리가 가득 차면 바닥에 놓인다.
- 전투 중 카드 사용과 솔리테어 이동에는 덱 편집의 희귀 슬롯 제한이 적용되지 않는다. 변환과 복제는 가능하다.
- 덱이 비어 있어도 편집을 확정할 수 있다.
- 덱에 카드를 넣는 이동에서 덱 용량과 희귀 슬롯을 검사한다. 편집을 확정할 때는 인벤토리와 제거 예정 인벤토리 카드의 합계가 용량을 넘는지 검사한다.
- 카드 판정은 이름이나 배열 순서가 아니라 카드 ID와 덱 ID를 사용한다.

## 13. 기록·디버그·저장

- 디버그 화면에는 전체 카드, 카드 풀 통계, 70개 조우 레시피의 적 도감이 있다. 같은 두 종류라도 대표 순서가 다른 레시피를 포함한다. 디버그 모드 덱 보유 한도는 10개다.
- 디버그 지역 덱 생성기는 지역과 개수를 받는다. `S=x+y+z`는 0(80%)·1(10%)·2(10%)이며 x,z≥-n, y≥1-n인 정수 조합에 `2^-(x²+y²+z²)` 가중치를 준다. 희귀 슬롯 C가 덱 용량을 넘으면 제외하고 각 S 안에서 가중 추첨한다. C는 `n+1+y`, 실제 희귀 카드는 50~90% 비율과 확률적 반올림으로 정한다. 희귀 풀은 전부 뽑기 전까지 중복되지 않는다.
- 에디션은 남은 예산 이하인 후보 중 `에디션 점수^1.2` 가중치 룰렛으로 추가한다. 희귀 슬롯을 제외한 일반 칸은 빈칸 1/4, 시작 카드 1/8, 일반 카드 3/8, 특별 카드 1/4 비율의 8-bag으로 슬롯 종류와 개수를 먼저 정한다. 이후 시작·일반 카드의 실제 종류는 일반 균등 복원추출보다 고유 카드 수가 평균 2/3이 되도록 응집 복원추출하며, 특별 카드는 기존처럼 균등하게 뽑는다. `덱 크기` 축복의 용량 +5는 카드와 에디션 생성이 모두 끝난 뒤 적용한다.
- 텔레메트리는 런, 전투, 턴, 가한·받은 피해, 카드 사용, 카드 획득 경로, 적별 피해, 덱 스냅샷을 기록한다.
- 탐험 진행은 버전이 붙은 브라우저 `localStorage` 저장으로 맵 화면에서 자동 저장·복원된다. 전투와 덱 편집 중 상태는 저장하지 않으며, 패배하거나 새 탐험을 시작하면 진행 저장을 지운다.
- 텔레메트리는 진행 저장과 별도로 브라우저 `localStorage`에 기록한다.
- 기록 내보내기 기능은 제거했다. 내부 텔레메트리 저장은 유지한다.

## 14. 삭제되었거나 아직 연결되지 않은 것

삭제되어 되살리지 않는 시스템:

- 카드 활성화/비활성화
- 적 열정과 각성
- `발광` 카드
- 물리/마법으로 나뉜 플레이어 공격 피해

정의는 있지만 일반 플레이 경로가 없는 콘텐츠:

- 전설 카드 6종
- 레거시 카드 `무쇠 난동`

아직 콘텐츠가 비어 있는 범위:

- 4~7지역 일반 적과 보스
- 전투 도중 저장과 불러오기
