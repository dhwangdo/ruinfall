# RUINFALL 게임 규칙

이 문서는 **현재 Godot 코드에서 구현된 게임**을 개괄한다. 구현 상세의 기준은 `godot/scripts/`이며, 포팅 전 설계·대조 자료는 `legacy-web-archive` Git 태그에 보존되어 있다.

## 게임 흐름

플레이어는 절차 생성 지도에서 이동하며, 적과 충돌하면 전투에 들어간다. 지도에는 전투 외의 상호작용 장소와 덱 금고가 있고, 획득한 카드·덱·티켓을 관리하며 탐험을 이어간다. 진행 저장과 복원은 Godot의 `user://` 저장 공간을 사용한다.

## 지도 탐험

지도 생성, 이동, 시야, 적과의 충돌, 자동 탐사는 각각 `map_generation_rules.gd`, `map_turn.gd`, `map_view.gd`, `map_enemies.gd`, `map_auto_explore.gd` 계열 코드가 담당한다. 전체 연결은 `main.gd`에서 조립된다. 실행과 내보내기 경로는 [Godot 실행 안내](../godot/README.md)에 정리한다.

일반 플레이어 시야는 위치에서 최대 6칸까지 퍼진다. 벽 너머로는 퍼지지 않으며, O 탐사의 시야 경계 계산도 같은 반경을 사용한다.

새로 생성하는 지역에는 세트피스를 배치하지 않는다. 지역별 덱 금고는 이전의 세트피스 포함 금고 총수를 먼저 120%로 반올림한 뒤, 그 결과를 다시 120%로 반올림한 수만큼 일반 지형에 배치한다.

지도 적은 한 번 `?` 경계 상태가 되면 다시 `Zzz` 수면 상태로 돌아가지 않는다. `!` 추격 상태에서 멀어지면 `?`로 내려갈 수 있다.

일반 적의 총 생성 수와 적끼리의 간격 규칙은 유지한다. 생성 후보 주변 8칸에서 이동 가능한 이웃이 두 연결 성분 이상으로 나뉘면 그 후보의 배치 가중치를 4배로 적용한다. 대각선 연결을 포함하며 지도 생성 시 한 번만 계산한다.

적은 플레이어와 이동 거리 2칸일 때 한 턴에 20% 확률로 인식 상태가 한 단계 올라간다.

디버그 시야는 플레이어 중심 좌우·상하 18칸의 37×37 정사각형이다. 벽은 시야를 가리지 않으며 범위 밖 미탐색 지형·적·바닥 물건은 무제한 공개하지 않는다. 본 지도·적 이동 표시·미니맵·금고 미리보기가 같은 표시 시야를 사용한다. 디버그 표시만으로 저장된 탐색 기록을 영구 확장하지 않으며 현재 시야 밖이라도 원래 탐색했던 지형은 기존의 어두운 기억 표시를 유지한다.

검색은 탐색 기록 또는 금고 발견 기록에 있는 미개방 덱 금고를 대상으로 한다. 금고를 방문하기 전이어도 위치·지도 시드로 덱과 포함 카드를 조회하며 카드 ID는 소비하지 않는다. 디버그 37×37 시야에 들어온 금고도 `known_deck_vaults`에 위치만 기록해 시야를 벗어난 뒤와 저장 복원 후에 검색할 수 있다. 일반 미탐색 금고는 표시하지 않는다. 결과는 검색어가 비어 있어도 표시하며 전체 데이터를 검색하되 목록 UI는 24개씩 페이지로 만든다.

열린 덱 금고 타일은 일반 바닥으로 표시하고 다시 상호작용할 수 없다. 같은 금고의 보상 덱이 이미 바닥이나 소유 덱에 있어도 중복 개방을 막는다.

새로 생성하는 금고는 위치·지도 시드에 따라 1.5% 확률로 1지역 높은 덱(열쇠 6개), 1.5% 확률로 2지역 높은 덱(열쇠 9개)을 가진다. 나머지는 해당 지역 덱과 기존 열쇠 3개 비용을 사용한다. 상위 지역 금고의 지도·검색 타일은 남색의 은은한 그라데이션 배경과 금색 테두리로 표시하며 별도 명칭을 붙이지 않는다. 미리보기와 실제 보상은 같은 생성 경로를 사용하고 이미 내용이 저장된 기존 금고는 유지한다.

O키 자동 탐사의 조사 완료 타일은 같은 지도 플레이 세션에서 중단·재시작·다른 이동을 거쳐도 유지한다. 재시작 시 경로·목표·적 위험 이력은 새로 계산한다. 새 게임·진행 불러오기·지도 시드 변경 시 조사 기록을 초기화한다. 조사한 타일도 새 골드가 있으면 수집 대상으로 선택할 수 있다.

## 카드 전투

카드는 내부적으로 사용 불가, 적 지정, 대상 비지정 모드로 구분한다. 카드 정의는 `card_catalog.gd`와 관련 카드 데이터 파일, 사용 판정은 `card_use.gd` 및 전투 규칙 스크립트가 담당한다. 전투 구성, 적 행동, 카드 이동·드로우·버리기 표현은 서로 다른 `battle_*.gd` 스크립트에 나뉘어 있다.

약화는 공격 피해를 50% 줄이고, 취약은 받는 공격 피해를 50% 늘린다. 두 효과는 더해 계산한 뒤 각 타격의 소수점 이하를 버린다. 공격이 아닌 피해에는 적용하지 않는다. 상태 숫자는 남은 턴 수이며, 새로 부여한 턴은 남은 수치에 더한다. 저항·증폭 상태와 이를 부여하던 카드·에디션은 제거했다.

일반 턴 진행은 플레이어 턴 종료 → 부식 발동 → 살아 있는 모든 적의 공격 → 플레이어의 기존 디버프 5종과 적의 기존 약화·취약 1 감소 → 모든 적의 공격 외 행동 → 다음 플레이어 턴 시작 순서다. 견고한 태세는 적 공격 후 남은 방어를 절반 보존한다. 공격과 부여가 섞인 패턴도 두 단계로 나누며, 새로 받은 디버프는 부여된 수치 그대로 다음 플레이어 턴에 적용된다. 적의 의도에는 `취약 2 부여`처럼 표시한다. 행동 취소는 해당 적의 두 단계를 모두 취소한다. 조건부 임시 힘·반격·피격 반응은 기존 조건에 따라 처리하고, 자폭은 해당 공격 직후 사망 및 사망 효과를 처리한다. 소환된 적은 생성된 턴에 행동하지 않는다. 흙·바위의 파일 배치는 기존 준비 시점을 유지한다. 추가 턴은 기존대로 적 행동을 건너뛴다.

방어는 단일 수치로 모든 공격을 막으며, 강인함이 음수여도 카드로 얻는 방어는 0 미만으로 내려가지 않는다. 마법방어와 별도 마법 공격 체계는 제거했으며, 별의 방주 및 마법 공격 적인 미라 사제·지룡·공허 해파리는 현행 생성 목록에 없다. 은검과 얼음 방패는 아래의 마법 저항 카드로 다시 추가했다. 카드 효과 키워드의 색은 방어 주황(#a65416), ★ 금색(#89601e), 마법 저항 파랑(#345e9b), 나머지 검정(#242620)으로 고정하며 설정에서 변경하지 않는다.

### 디버프와 마법 저항

다섯 디버프의 숫자는 남은 턴 수이며 추가 부여 시 더한다. 부식은 내 턴 종료 시 방어를 절반으로 줄이고 소수점 이하는 버린다. 마비는 한 턴에 카드 사용을 3장으로 제한하며, 예약·선택·솔리테어 이동은 사용 횟수로 세지 않는다. 혼란은 카드의 드로우·파일 선택까지 끝난 뒤 손패의 카드 한 장을 무작위로 버린다. 현재 사용 중인 카드는 후보에서 제외한다. 효과가 끝나기 전에 혼란이 없어지면 버리기를 건너뛴다. 혼란의 버리기도 탁월수와 이계의 힘을 발동한다.

혼란으로 예약 카드가 버려지면 남은 사용 큐 전체를 취소한다. 버려진 카드는 버린 상태를 유지하고 나머지는 손패에서 다시 조작할 수 있다. 이미 끝난 카드의 효과와 비용은 되돌리지 않는다.

마법 저항 X는 취약·약화·부식·마비·혼란을 부여받을 때 각각의 부여량을 X만큼 줄이며, 최솟값은 0이다. 저항 자체는 소모되지 않는다. 피해·힘 감소·강제 버리기·카드 생성에는 적용하지 않는다. 임시 저항은 적의 효과 단계까지 유지된 뒤 다음 내 턴 시작에 만료한다. 일반 저항은 전투 내내 유지하며 중첩된다.

이번 턴만 얻는 힘과 마법 저항도 실제 힘·마법 저항 수치에 즉시 더한다. 만료할 양은 별도로 기록해 다음 내 턴이 시작되기 전에 뺀다. 전투 화면에는 합쳐진 힘 수치와 방어 아이콘 옆의 파란 마법 저항 방패를 표시하고, 만료 예정량은 별도 모래시계 아이콘의 툴팁에 안내한다.

## 덱과 서비스

덱 편집, 카드 희귀도·에디션·스티커, 덱 금고, 제단·변환기·땜장이 동작은 해당 `deck_*`, `card_*`, `sticker_*` 스크립트와 `sticker_service_controller.gd`, `deck_storage_service.gd`, `deck_editor_view.gd`, `main.gd`의 화면 연결을 기준으로 한다. 정확한 제한과 가격은 해당 규칙 구현을 확인한다.

디버그 진입은 현재 덱을 유지하며 ALL 덱을 자동 지급하지 않는다. 디버그 지급 메뉴의 `ALL 덱 생성` 버튼으로 모든 카드가 든 덱을 바닥에 생성할 수 있다. 편집창에서 덱을 통째로 주워도 내부 카드는 그 덱 소속으로 기록하므로 임시 추가 반짝임이나 덱 밖 카드에만 허용하는 이동 예외가 적용되지 않는다.

덱 보유 한도는 일반 모드 3개, 디버그 모드 100개다. 디버그를 꺼도 이미 가진 초과 덱은 보존하며 추가 습득만 제한한다. 덱이 많으면 편집창은 세로 스크롤을 사용하고 지도 덱 선택은 목록으로 표시한다.

### 무작위 덱 생성 (2026-11-17)

귀속 전설(카시오페이아·레오·호롤로지움) 에디션이 없는 생성 덱은 1% 확률로 단일 카드 구성을 사용한다. 로열이면 최종 용량 전체를 소원으로 채운다. 그 외에는 찬 희귀 슬롯의 카드와 빈 희귀 슬롯을 그대로 유지하고, 나머지 슬롯을 돌격!!·늑대 부적·거북이 부적 중 하나로 가득 채운다. 각 후보는 균등 추첨하며 기존 에디션·스티커 예산과 무작위 이름을 유지하고 별도 표시는 없다.

`deck_generation_model.gd`가 평균·점수 편차 기반 생성 모형을 사용한다. 지역 r에서 에디션 적용 전 용량 평균은 `20 + 2.5r`, 일반 희귀 슬롯은 `1 + 0.5r`(찬 슬롯:빈 슬롯 평균 3:1), 에디션 점수는 `0.5r`, 스티커는 `0.5 + 0.5r`다. 귀속 전설 에디션의 추가 희귀 슬롯과 로열의 슬롯 전환은 이 목표와 점수 계산에서 제외한다.

가치 계산은 `12x + 8y1 + 6y2 + 15z + 5w`를 유지한다. 점수 표준편차 목표는 `15 + 3(r-1)`이다. 1~10지역은 연속된 정수 격자 위의 최대 엔트로피 분포를 사용한다. 유효한 구성마다 `exp(일차식 + 이차식)`에 비례하는 양의 확률을 주며, 정수 0/큰 값 혼합이나 교환 단계는 사용하지 않는다.

평균 5개와 공분산 15개를 직접 맞춘다. 가중치 a=(12,8,6,15,5), λ=목표 점수 분산/494일 때 공분산 목표는 `λ[I + 0.05(I - aaᵀ/494)]`다. a 방향의 점수 편차를 보존하고 수직 방향 분산은 5% 크게 두어 최소 방향을 유일하게 정하면서 추가 상관을 작게 한다. 1~10지역의 이론 상관계수 절댓값 최대는 약 0.0177이다.

최대 엔트로피는 명시적인 유한 상한과 실제 생성 조건 아래에서 계산한다. 모든 정수 중 무한한 범위를 포함하는 분포라는 뜻은 아니다. 상한의 확률은 검증표에 기록하며, 1~10지역 최대 약 2.23e-7이다. 확률의 로그는 이차식이므로 유효한 이웃 구성 사이에 기존 혼합 분포 같은 인위적 구멍을 만들지 않는다. 지역 번호 자체는 정수다.

`godot/tools/build_deck_maxent.py`가 NumPy/SciPy로 계수를 사전 계산한다. `assets/data/deck_maxent.json`은 약 23KB이며 Windows·Web 내보내기에 포함된다. 게임은 이 표로 정확한 기각 추출을 수행하며 약 92%의 제안을 채택한다. 유한 횟수 교환이나 마르코프 체인의 수렴에 의존하지 않는다. 에디션 목록·점수 변경 시 계수표를 다시 생성해야 한다.

최대 엔트로피 검증 범위는 1~10지역이다. 그 이후에는 교환 없는 정수 평균·분산 추첨으로 대체하며 동일한 최대 엔트로피·공분산 보장을 하지 않는다. 유한한 에디션 총점 때문에 같은 목표를 무한히 유지할 수 없으며 에디션 평균은 총점보다 1 작은 값으로 제한한다. 초기 구성의 유효성 재추첨 및 상한이 작동하는 후반 지역은 목표에서 벗어날 수 있다.

에디션 점수를 정확히 채우고 용량·희귀 슬롯·스티커가 들어가는 조합을 추첨한다. 기존 등급 가중치 추첨 결과가 유효하면 채택하고, 반복 실패 시 유효한 조합 중 추첨한다. 카드 내용 때문에 스티커를 붙일 수 없으면 내용만 다시 구성하며 생성 벡터 전체를 다시 뽑지 않는다. 갬빗 용량 -20과 압축 -20%는 생성한 용량에 적용한다.

에디션은 남은 예산과 미선택 에디션이 있는 1·2·3점 등급부터 1:2:3 가중치로 추첨하고, 해당 등급 안에서 균등 추첨한다. 중복 없이 예산을 차감하며 반복한다. 갬빗의 용량 -20을 먼저 적용하고 압축의 -20%를 적용한 뒤 소수점을 버린다. 용량·슬롯·스티커 조건에 맞는 에디션 조합만 사용한다.

귀속 전설은 덱에서 꺼내기·덱 간 이동·제거·제물·변환을 금지하며 스티커 부착은 허용한다. 전투 중 사용·버리기·재련 규칙은 그대로 적용한다. 자동망치는 효과가 별도인 치환 합금·흑요석 단검을 후보에서 제외한다. 기존 에디션의 생성 및 전투 효과는 제거했다. 새 생성 규칙은 새로 생성되는 덱부터 적용한다.

돌격!!은 특별 등급의 0코스트 공격으로 피해 12 후 자신에게 취약 1을 부여한다. 자기 취약도 마법 저항의 영향을 받는다. 제단 기본 비용은 200골드, 변환기는 40골드, 땜장이 기본 비용은 닻·야광공룡 40골드, 태엽장치·책갈피·연·파랑새 100골드, 월석·혜성·갈고리·낙하산 200골드다. 이용 횟수에 따른 기존 1.5배 인상은 유지한다.

## 체력·적 능력치 시험 조정 (2026-11-17)
새 게임은 체력 70/70으로 시작한다. 적 카탈로그의 기준 체력·공격 피해·힘 획득량(특성 포함)은 기존 대비 각각 15% 올리고 가장 가까운 정수로 반올림했다. 새끼 바퀴도 포함한다. 일반 적 초기 체력은 새 기준의 95~105% 양끝을 정수 반올림한 범위에서 균등 추첨한다. 보스와 고정 체력 특성은 기준 체력을 그대로 사용한다. 공격 횟수·디버프·방어·회복·비공격 피해는 유지한다. 기존 진행 중 저장의 체력은 자동 변환하지 않는다. 새 게임 및 다음 지역 포탈 진입 시 신들의 비탄 3회(적·소환수 체력 70%, 안전 구역 포탈 진입 시 0)가 적용되며, 한 지역에서 12승 이상 거두면 1승마다 카르마 단계가 1씩 올라(적 힘 +단계, 최대 체력 +10%×단계) 포탈 이동 시 초기화된다.

주황 슬라임은 전투 시작 시 유독성 점액 1장을 손패에 넣고, 몸통 내려찍기 때도 피해 9와 함께 유독성 점액 1장을 손패에 추가한다. 실을 짜는 거미는 이번 턴에 성공한 솔리테어 행동마다 받는 피해가 3 증가하며, 증가량은 중첩되고 턴 종료 시 초기화된다.

하수구 쥐의 고유 특성 「갉아먹기」: 행동할 때마다 파일에서 카드를 1장 버린다. 파일 맨 위 카드 중 희귀도가 높은 카드를 우선하며, 다단 공격도 행동당 한 번만 발동한다. 행동 취소 시에는 발동하지 않는다. 버리기는 개별 의도 설명에 표시하지 않고 특성 아이콘 툴팁으로 안내한다.

일반 카드 「연속 베기」: 1코스트, 피해 6. 1코스트 카드로 재련하면 같은 피해로 한 번 더 공격한다. 시작 덱에 1장 포함한다.

전투 교본·병법서는 손패에 있는 동안 실제 힘·강인함 수치를 올린다. 손패에서 빠지면 해당 카드의 기여분을 잃고, 보존되어 남아 있으면 유지한다. 피해·방어에 별도 보너스로 중복 합산하지 않는다. 병법서를 사용해 얻은 영구 힘·강인함은 소멸 후에도 남는다.
