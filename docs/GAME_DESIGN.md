# RUINFALL 게임 규칙

이 문서는 **현재 Godot 코드에서 구현된 게임**을 개괄한다. 구현 상세의 기준은 `godot/scripts/`이며, 포팅 전 설계·대조 자료는 `archive/legacy-web/`과 `archive/porting/`에 보존한다.

## 게임 흐름

플레이어는 절차 생성 지도에서 이동하며, 적과 충돌하면 전투에 들어간다. 지도에는 전투 외의 상호작용 장소와 덱 금고가 있고, 획득한 카드·덱·티켓을 관리하며 탐험을 이어간다. 진행 저장과 복원은 Godot의 `user://` 저장 공간을 사용한다.

## 지도 탐험

지도 생성, 이동, 시야, 적과의 충돌, 자동 탐사는 각각 `map_generation_rules.gd`, `map_turn.gd`, `map_view.gd`, `map_enemies.gd`, `map_auto_explore.gd` 계열 코드가 담당한다. 전체 연결은 `main.gd`에서 조립된다. 지원 입력과 상호작용은 [Godot 실행 안내](../godot/README.md)에 정리한다.

## 카드 전투

카드는 내부적으로 사용 불가, 적 지정, 대상 비지정 모드로 구분한다. 카드 정의는 `card_catalog.gd`와 관련 카드 데이터 파일, 사용 판정은 `card_use.gd` 및 전투 규칙 스크립트가 담당한다. 전투 구성, 적 행동, 카드 이동·드로우·버리기 표현은 서로 다른 `battle_*.gd` 스크립트에 나뉘어 있다.

## 덱과 서비스

덱 편집, 카드 희귀도·에디션·스티커, 덱 금고, 제단·변환기·땜장이 동작은 해당 `deck_*`, `card_*`, `sticker_*` 스크립트와 `main.gd`의 화면 연결을 기준으로 한다. 정확한 제한과 가격은 해당 규칙 구현을 확인한다.

## 변경 시 주의

- 이 문서의 개괄은 개별 수치나 모든 예외를 대신하지 않는다. 세부 규칙은 현행 GDScript 구현을 확인한다.
- 코드에 없는 규칙을 포팅 기록만으로 현재 규칙처럼 기술하지 않는다.
- 포팅 당시의 웹 대조 자료는 기록으로만 보존한다.
