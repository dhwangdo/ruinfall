# RUINFALL Godot 포트

Windows와 웹으로 내보내는 Godot 프로젝트입니다. 공개 웹 게임도 이 프로젝트의 Web 내보내기 결과를 사용합니다.

## 웹·PC 공통 표현과 카드 조작

- 모든 카드 정의는 `use_mode`를 명시합니다: `unplayable`(사용 불가), `targeted`(적 지정), `untargeted`(대상 없이 사용). 조작·규칙은 `scripts/card_use.gd`의 `mode`, `is_playable`, `requires_target`을 사용합니다. 공격/스킬 종류와 별개이며 전체 공격은 `untargeted`입니다. 에너지 부족·처리 대기 등의 일시적 제한도 별도입니다. 기존 `playable` 필드는 이전 저장 호환용이고, `use_mode`가 우선합니다. 이전 카드에 분류가 없으면 처음 조회할 때 기존 정보로 보완합니다.
- 웹과 PC는 포함된 `assets/fonts/PretendardVariable.woff2`와 같은 굵기·크기 설정을 사용합니다. 운영체제 설치 폰트에 의존하지 않습니다. 실행 환경을 이유로 화면 표현이나 조작을 나누는 것은 기술적으로 필요한 경우로 한정합니다.
- 전투 손패 숫자키는 누르는 동안 카드를 들고, 떼면 복귀합니다. 손패 카드를 좌클릭해도 들 수 있습니다. 든 상태에서 좌클릭하면 유효한 대상에 사용·이동하고, 유효하지 않은 곳을 누르거나 우클릭·Esc를 누르면 복귀합니다. 파일로 옮기는 솔리테어 판정이 카드 사용보다 우선합니다.
- 카드의 이동과 취소 복귀는 빠르게 출발해 감속합니다. 카드를 든 동안 다른 손패 카드의 확대·툴팁을 막습니다. 손패 버리기 중 숫자키는 해당 카드를 즉시 버립니다. 파일로 옮기는 판정은 계속 우선합니다.
- 대상 비지정 카드는 커서를 따라갑니다. 손패 높이의 위쪽 40%까지 카드 사용을 허용하며 화살표는 표시하지 않습니다. 사용하면 실제 표시 위치에서 중앙으로 210ms 이동하고 110ms 멈춘 뒤, 화면 우측 하단 바깥으로 270ms 이동하며 사라집니다.
- 대상 지정 카드는 집으면 화면 중앙에 놓고, 카드에서 커서로 주황 화살표를 표시합니다. 주황 화살표 머리는 커서를 따라갑니다. 적 위에서 좌클릭하면 현재 카드 위치에서 그 적에게 260ms 동안 이동하며 사라집니다. 마우스로 손패에서 12px 이상 위로 끌어올려 카드 사용 높이에 한 번 도달하면 집기를 유지하고, 좌클릭을 떼어도 유지합니다. 숫자키는 계속 누르는 동안만 집습니다. 유효한 파일 위에서는 솔리테어 이동이 우선합니다.
- 두 종류 모두 커서를 손패 높이의 82% 아래로 내리면 취소하고 부드럽게 복귀합니다.
- 손패에서 파일로 옮길 때는 현재 카드 표시 위치에서 새 파일의 맨 위 카드 위치까지 260ms 동안 감속 이동합니다. 파일 카드 크기로 줄어들며 불투명도를 유지하고, 이동 종료 후 규칙 계산 결과를 반영합니다. 카드 사용처럼 사라지지 않습니다.
- OS의 애니메이션 감소 설정은 반환값이 `1`일 때만 적용합니다. 설정을 조회할 수 없다는 `-1`을 감소 요청으로 해석하지 않습니다.
- 덱 편집 중 인벤토리·바닥에서 새로 넣은 카드 묶음은 기존 웹처럼 흐려짐과 채도 변화를 반복합니다. 원래 덱에 있던 카드는 그대로 표시하며, 새 추가 카드에는 제거 아이콘을 붙이지 않습니다. 편집을 닫으면 추가 예정 표시를 끝냅니다.
- 전투 생성 카드 번호는 일반 덱 카드 및 `-1` 선택 없음 표시와 분리합니다. 음수 에너지는 숫자 그대로 표시하고, 구체 안의 채움만 0~100%로 제한합니다.

## 웹 배포

- 공개 주소: https://dhwangdo.github.io/ruinfall/
- Godot 4.7.2와 같은 버전의 내보내기 템플릿을 사용합니다.
- Web 프리셋은 Compatibility 렌더러와 단일 스레드를 사용하므로 별도 교차 출처 격리 헤더가 필요하지 않습니다. 지도는 웹에서 지역별로 나눠 생성합니다.
- 저장소 루트에서 `godot --headless --editor --path godot --import` 후 `out` 폴더를 만들고 `godot --headless --path godot --export-release Web ../out/index.html`로 내보냅니다.
- `main`에 올리면 `.github/workflows/deploy-pages.yml`이 엔진·템플릿을 설치하고 스크립트 검사, Web 내보내기, Pages 배포를 수행합니다. 기존 React 웹 빌드는 공개 배포에서 제외합니다.
- 웹의 탐험 저장은 브라우저 IndexedDB의 `user://`에 보관됩니다. Windows 저장과는 별개이며 전투 도중 저장하지 않는 게임 규칙은 동일합니다.

2026-11-12: 현재 작업본을 활용하고 **GDScript를 유지**하기로 결정했습니다. 작업 범위와 실제 검증 결과는 [포팅 체크리스트](../docs/GODOT_PORT_CHECKLIST.md), 판단 근거는 [포팅 검토 문서](../docs/GODOT_PORT_REVIEW.md)를 따릅니다. 단일 적 조우의 연결과 보정·턴 종료 연타를 수정하고 대표 전투 B01~B07을 통과한 단계이며 전체 이식 완료 상태는 아닙니다. 실행 중인 게임 창에는 소스 수정이 자동 반영되지 않으므로 최신 코드를 확인하려면 게임을 다시 실행합니다.

## 실행

Windows에서는 `Run RUINFALL.cmd`를 실행합니다. 개발용 Godot 4.7+가 있으면 현재 프로젝트를 엽니다. Godot이 없는 PC에서는 `build/RUINFALL.exe`를 실행합니다. 별도 실행 파일은 Godot 편집기의 **Editor > Manage Export Templates**에서 현재 Godot 버전의 Windows 템플릿을 설치한 뒤 `Export Windows.cmd`를 실행해 만듭니다. 실행 파일에는 게임 데이터가 포함되므로 플레이어 쪽에는 Godot이 필요하지 않습니다.

포팅 우선순위는 새 탐험부터 지도·전투·보상·덱 관리까지 실제 플레이 흐름을 잇고, 주요 규칙과 화면 배치를 브라우저판에 맞추는 것입니다. 세부 애니메이션과 장식은 흐름이 안정된 뒤 다듬습니다.

## 전투 규칙 검사

최근 카드 분류·입력·이동 연출 검사는 Godot 실행 파일에 `--headless --path godot --script res://tests/card_use_probe.gd`, `res://tests/battle_hand_input_probe.gd`, `res://tests/battle_card_hold_probe.gd`를 각각 지정해 실행합니다. 이 검사들은 사용자 탐험 저장을 읽거나 쓰지 않는 분리 화면에서 실행합니다.

저장소 루트에서 `rtk test node --experimental-strip-types --test tests/godot-solitaire.test.mjs tests/godot-battle-flow.test.mjs`를 실행합니다. 현재 웹의 실제 규칙과 Godot의 실행 결과를 대조합니다. 솔리테어 이동 40사례, 전투 시작 보정·초기 배치·전체 공격·다음 턴 23사례이며 이 검사는 화면 조작 검사를 대신하지 않습니다.

기본 엔진은 저장소의 `work/godot-tools/4.7.2/Godot_v4.7.2-stable_win64_console.exe`입니다. 다른 Godot 4 실행 파일은 `GODOT_BIN` 환경 변수에 절대 경로를 지정합니다. 두 경로 모두 없으면 검사를 건너뛰었다고 표시하므로 통과와 구분합니다.

## 현재 들어간 흐름

- 단일·복수 적 조우 모두 카르마와 신들의 비탄을 적용합니다. 비탄은 최대 체력을 바꾸지 않고 현재 체력만 줄입니다. 턴 종료 전환 중에는 추가 입력을 막고, 새 탐험·전투를 시작하면 이전 전환 결과를 취소합니다.
- 앞면 파일 카드를 잡으면 그 카드부터 맨 위까지의 묶음을 드래그합니다. 순서와 중간 뒷면을 유지하고, 별은 잡은 카드 기준으로 한 번만 소모합니다. 각 재련은 이동 전 목적지를 기준으로 판정합니다. 잘못된 드롭과 오래된 카드 위치 입력은 거절합니다.
- 전투 손패에서 Space로 현재 비용·희귀도순 정렬, E로 턴 종료를 합니다. 숫자키 1~9는 보이는 손패를 들고 다른 숫자로 전환하며 같은 숫자·Escape로 취소합니다. 우클릭은 키보드 드래그를 유지합니다. 일반 전투의 대표 입력을 검증했으며 강제 버리기 단축키 등은 후속 확인 대상입니다.
- 전투 배치와 기본 입력은 웹의 1280×820·1440×900 화면과 비교했습니다. 적이 버릴 파일의 점선·수량 배지는 체크리스트의 UI01에서 맞추고 확인했습니다. 카드 글꼴 등 남은 시각 차이는 C01에 남아 있습니다. 전체 UI 일치 완료는 아닙니다.
- 전투 화면은 브라우저 데스크톱판의 3열 배치를 따릅니다. 왼쪽에 플레이어 초상·체력·방어와 상태, 가운데에 파일, 오른쪽에 적과 다음 행동을 둡니다. 136×191px 손패는 하단에서 화면 너비를 사용하고, 에너지 구슬과 턴 종료는 오른쪽 아래에 둡니다. 파일 카드는 121×170px, 27px 간격으로 전체 스택을 표시합니다. 파일과 손패는 각각 가로로 넘길 수 있고, 적·상태 정보는 필요한 경우 세로로 넘깁니다. 손패 카드의 직접 피해·방어 수치는 현재 힘·증폭·강인함을 반영하고, 적을 선택하면 그 적의 저항도 반영합니다. 광채는 이번 턴에 사용한 횟수에 따라 피해가 증가합니다. 스티커·에디션 툴팁은 파란색 배경으로 표시합니다. 에너지·상태 배지에 마우스를 올리면 설명을 확인할 수 있고, 적 상태 설명은 해당 적의 상태 효율을 반영합니다.
- 덱 편집은 인벤토리·덱·바닥 3열로 나눴습니다. 각 열은 독립적으로 스크롤하며, 카드 드래그·우클릭 반환·바닥 배치·추출 티켓 동작을 기존대로 유지합니다. 바닥의 덱 금고 더미는 눌러 줍거나 빈 덱 슬롯으로 드래그할 수 있고, 보유 덱 머리글을 드래그해 순서를 바꾸거나 바닥으로 옮길 수 있습니다.
- 시작 화면에서 7개 지역으로 이어지는 절차 생성 지도 진입
- 지역별 212×47 타일, 지역 사이 5줄 바위 경계
- 반경 4 안의 지형을 시야로 밝히며, 바위 뒤로는 시야가 이어지지 않습니다. 마우스로 지도를 이동·확대
- 지도 상단에 체력·골드·열쇠·덱 정보와 한 턴 쉼·지도 검색·인벤토리·덱·설정 버튼을 배치합니다. 한 턴 쉼은 플레이어가 제자리에 머물며 적만 한 번 행동하게 합니다. 좌측 위에는 브라우저판 기본 크기인 245×245 미니맵을 표시합니다. 좌측 위 손잡이를 끌어 미니맵 위치를 옮기고, 안쪽을 끌어 지도를 이동하며, 휠로 확대·축소하고, 우하단 손잡이로 크기를 바꿀 수 있습니다. 크기·위치·플레이어 표식·전투 전 덱 확인·애니메이션 툴팁 설정은 `user://settings.cfg`에 저장됩니다. ★·재련 키워드 설명에 3초 머무르면 손패 카드가 세 파일 사이를 이동하는 예시와 재련 예시를 브라우저판처럼 반복 표시합니다. 미니맵은 발견된 타일만 표시하고, 덱·카드·소모품이 놓인 일반 타일은 청록색으로 표시합니다. 금화는 미니맵에 표시하지 않습니다.
- 지도 검색은 상단 검색·필터 아래에 결과 목록과 상세 패널을 나눠 둡니다. 덱·장소 결과는 실제 지도 타일로, 아이템 결과는 카드 미리보기로 보여주며, 선택한 결과 옆에 발견한 지역 지도와 강조 핑을 표시합니다. 덱 상세에는 덱 카드도 표시합니다. 이름·카드 설명·에디션으로 찾고, 띄어 쓴 검색어는 모든 단어를 포함해야 하며, 아이템은 희귀도순입니다. 땜장이는 부여할 스티커 그림과 설명을 표시합니다. 핑은 맵 타일과 미니맵에서 강조되고 화면 밖 화살표를 두 번 누르거나 도착하면 해제됩니다.
- WASD·방향키·HJKL로 이동하고 숫자패드 1~9로 8방향 이동합니다(5는 한 턴 쉼). 키를 누르고 있으면 20ms 간격으로 이동합니다. 발견한 먼 타일을 클릭하면 적과 가까운 구간 노출을 최소화하는 경로로 자동 이동. 설정·덱·인벤토리·장소 화면에서 Esc를 눌러 돌아갈 수 있습니다.
- 플레이어가 이동하면 이동 전 타일의 반경 4 안에 있는 적만 턴을 진행합니다. 이동 후 타일까지 벽과 지형을 반영한 최단 이동 가능 경로가 1칸인 적은 100%, 2칸인 적은 10% 확률로 감지합니다. 수면 적은 깨어나고, 깨어난 적은 다시 감지하면 경계 상태가 됩니다. 깨어난 적은 절반 확률로 주변을 배회하며, 경계한 적은 95% 확률로 플레이어에게 가까워지는 경로를 택합니다. 보스는 제자리를 지키고, 적은 안전 구역에 들어오지 않습니다. 시야 밖의 현재 위치는 감추고 마지막으로 본 위치만 어둡게 표시합니다.
